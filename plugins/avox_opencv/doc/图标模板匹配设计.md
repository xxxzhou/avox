# 图标模板匹配 (Icon / Template Matching)

在场景图 (`IImageBuffer`) 中定位图标/模板位置, 供 Agent 点击。
已实现于 `plugins/avox_opencv/` (工厂注册名 `"opencv"`), 核心接口 `src/avox/AvoxVision.h`。
算法参考 MaaFramework — `cv::matchTemplate` + NMS + green_mask。

---

## 接口 (`src/avox/AvoxVision.h`)

```cpp
// 匹配方法 (enum 值独立于 OpenCV, 实现内映射到 cv::TemplateMatchModes)
enum class TemplateMatchMethod {
  none = 0,          // 未设置 -> 回退默认 ccoeffNormed
  sqdiffNormed = 1,  // -> TM_SQDIFF_NORMED, 支持 green_mask
  ccorrNormed  = 2,  // -> TM_CCORR_NORMED, 支持 green_mask
  ccoeffNormed = 3,  // -> TM_CCOEFF_NORMED, 光照鲁棒 (默认), 不支持 green_mask
};

enum class MatchOrderBy { none = 0, horizontal, vertical, score, area };

// 单次命中结果 (POD, 跨 DLL 安全)
struct MatchResult {
  int32_t x, y, w, h;        // 命中框 (scene 坐标系, 左上角 + 宽高)
  int32_t templateIndex;     // 来自哪个模板 (addTemplate 返回值, 多模板区分来源)
  double score;              // 置信度 [0,1], 越大越好
};
// 框中心 (Agent 点击用): vec2i getMatchCenter(const MatchResult& r)

class ITemplateMatcher {
 public:
  virtual ~ITemplateMatcher() = default;
  // 配置 (match 前设置)
  virtual void setMethod(TemplateMatchMethod) = 0;        // 默认 ccoeffNormed
  virtual void setOrderBy(MatchOrderBy) = 0;              // 默认 horizontal
  virtual void setGreenMask(bool enable) = 0;             // 模板纯绿(0,255,0)区域当透明
  virtual void setNmsIoU(float iou) = 0;                  // 默认 0.2, 设 0 关闭
  virtual void setRoi(int32_t x, int32_t y, int32_t w, int32_t h) = 0;
  virtual void clearRoi() = 0;
  // 模板 (可多个, 每个独立阈值; 返回下标, 失败 -1)
  virtual int32_t addTemplate(IImageBuffer* tmpl, double threshold) = 0;
  virtual int32_t addTemplatePath(const char* path, double threshold) = 0;  // 便捷: 文件路径
  virtual void clearTemplates() = 0;
  // 执行 + 结果
  virtual int32_t match(IImageBuffer* scene) = 0;         // 返回命中数
  virtual int32_t getMatchCount() = 0;
  virtual bool getMatch(int32_t index, MatchResult* out) = 0;  // index 支持 Python 负索引
  virtual float getMatchTimeMs() = 0;
  virtual const char* getLastError() = 0;
};
```

获取实例: `AvoxManager::Get().templateMatcherHub.create("opencv")` (OpenCV 缺失返回 nullptr 优雅降级)。

---

## 算法要点 (`plugins/avox_opencv/TemplateMatcher.cpp`)

1. **通道统一** `toBgrMat`: 按 `ImageType` 把 scene 与模板都 `cvtColor` 到 `BGR(CV_8UC3)` — `OpencvHelper` 把 `rgba8`/`bgra8` 都映射成 `CV_8UC4` 且不分通道顺序, 直接匹配会错。模板 `addTemplate` 时转好存储, scene `match` 时转。
2. **匹配** `cv::matchTemplate`, 默认 `CCOEFF_NORMED`; `SQDIFF` 结果做 `1 - score` 翻转, 统一为"越大越好"。
3. **green_mask** `cv::inRange` 找纯绿生成 mask (绿=0 忽略, 无绿/全绿则空)。`cv::matchTemplate` 的 mask 仅 sqdiff/ccorr 支持, 故 `ccoeffNormed + mask` 自动降级 `ccorrNormed` 并记入 `getLastError()`。
4. **多目标** 全图扫描结果矩阵 (不用 `minMaxLoc`), 收集 `score >= threshold - 0.2` 的候选并记 `templateIndex`, 再 **NMS** (IoU=0.2, 覆盖比例版) 去重。
5. **坐标** 始终相对 scene 左上角; ROI 只缩小搜索范围, 命中已 `+roiOffset` 映射回 scene (拿到即可直接点击, 无需再偏移)。
6. **线程** 实例非线程安全 (多线程各自 `create`); `match` 内部对 buffer 深拷贝, 不与截图线程竞争。

## 用法

```cpp
#include "avox/AvoxVision.h"
#include "avox/module/AvoxManager.hpp"
using namespace avox;

auto* raw = AvoxManager::Get().templateMatcherHub.create("opencv");
std::unique_ptr<ITemplateMatcher> m(raw);            // raw==nullptr 表示 OpenCV 未启用
m->setGreenMask(true);                                // 模板中不想匹配的区域涂纯绿
m->addTemplatePath("assets/btn_start.png", 0.8);     // 返回 0
m->addTemplatePath("assets/btn_set.png", 0.8);       // 返回 1

IImageBuffer* scene = createImageBuffer();
player->getSurfaceRender()->screenShot(scene);       // 截图 (RGBA)
std::unique_ptr<IImageBuffer> sceneGuard(scene);

m->match(scene);
for (int32_t i = 0; i < m->getMatchCount(); ++i) {
  MatchResult r;
  m->getMatch(i, &r);
  // r.templateIndex: 0=btn_start, 1=btn_set
  // vec2i c = getMatchCenter(r); agent.click(c.x, c.y);
}
```

demo: `samples/functest/templatematchtest.cpp` (无参运行合成图自测, 双模板验证 `templateIndex` 区分)。
