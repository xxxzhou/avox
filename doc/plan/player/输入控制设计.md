# 输入控制设计（鼠标/键盘注入）

> 跨平台 GUI 输入注入 SDK：鼠标移动/点击/拖拽/滚轮 + 按键/组合键/文本输入 + 拟人化轨迹/抖动。
> 纯输入层，不含视觉定位；上层（应用 / SWIG / 测试）负责「定位→调本层注入」。

## 1. 目标与定位
- 提供 avox 的输入注入能力，作为 first-class 公共 API（同 `AvoxVision.h`），供 C++ / SWIG(C#/Java/Node) 应用做自动化、回放、压测。
- 输入注入 = OS API（Win32 `SendInput` / X11 `XTest` / macOS `CGEvent`），**编译期**按平台选定 → 落 `src/avox_windows/`、`src/avox_linux/`、`src/avox_ios/`（与 `src/avox/` 平级的平台目录），**不是** plugin：无第三方库可探测，套不上 `loadModule()` 降级模型。也不是 `platform/`（那是 SWIG/Avalonia，无编译代码）。
- 抽象接口放核心 `src/avox/AvoxInput.h`（纯虚 + 跨 DLL 安全签名），拟人化基类放 `src/avox/vision/BaseInputController.hpp`（范本 `BaseTextRecognizer`：组合接口 + 共享基础设施）。

## 2. 分层架构
```
src/avox/AvoxInput.h              IInputController 纯抽象 + createInputController AVOX_EXPORT
        │  虚函数分发（编译期一平台一实现）
src/avox/vision/BaseInputController.hpp   拟人化基类(setter直接实现 + 贝塞尔/jitter/RNG)
        │  继承
src/avox_windows/                src/avox/vision/ (兜底)
 InputController.{hpp,cpp}       InputNoop.cpp
 : public BaseInputController     : public BaseInputController
 SendInput 全功能                  !WIN32 → false
```
- **无需改 CMake**：`src/CMakeLists.txt` 已有 `add_sub_path(avox_windows ...)`（WIN32）与 `add_sub_path(avox ...)`，`file(GLOB *.cpp)` 自动收集新文件。
- **链接保证**：`createInputController` 全局唯一。Windows 走 `avox_windows/InputController.cpp`（`#if defined(_WIN32)`）；非 Windows 走 `avox/vision/InputNoop.cpp`（`#if !defined(_WIN32)`）。两个守护互斥，永不重复定义。
- **目录重构**：原 `avox/neural/` 已改名为 `avox/vision/`（视觉+输入共用），`AvoxVision.cpp`/`BaseTextRecognizer.hpp` 从 `avox/` root 搬入 `avox/vision/`。

## 3. 抽象接口 IInputController（src/avox/AvoxInput.h）
```cpp
enum class MouseButton { left=0, right, middle, x1, x2 };
enum class KeyCode { none, a..z, num0..num9, f1..f12, space,enter,esc,tab,
  backspace,del,home,end,pageUp,pageDown, up,down,left,right,
  shift,ctrl,alt,win, capsLock, numLock };
class IInputController {
 public:
  virtual ~IInputController()=default;
  // —— 鼠标 ——
  virtual bool moveTo(int32_t x,int32_t y)=0;                       // 参照 setTargetWindow
  virtual bool moveBy(int32_t dx,int32_t dy)=0;                     // 屏幕相对(不受窗口原点影响)
  virtual bool mouseDown(MouseButton b)=0;
  virtual bool mouseUp(MouseButton b)=0;
  virtual bool click(int32_t x,int32_t y,MouseButton b=left)=0;
  virtual bool doubleClick(int32_t x,int32_t y)=0;
  virtual bool drag(int32_t x1,int32_t y1,int32_t x2,int32_t y2,
                    MouseButton b=left)=0;                          // down→插值移动→up
  virtual bool scroll(int32_t dx,int32_t dy)=0;                     // 横/竖, 单位=滚轮格
  virtual bool getCursorPos(vec2i* pos)=0;                  // pos->x/y(参照 setTargetWindow)
  // —— 键盘 ——
  virtual bool keyDown(KeyCode k)=0;
  virtual bool keyUp(KeyCode k)=0;
  virtual bool press(KeyCode k,int32_t holdMs=0)=0;
  virtual bool hotkey(const KeyCode* keys,int32_t n)=0;             // Ctrl+C 等
  virtual bool typeText(const char* utf8)=0;                        // Unicode 输入
  virtual bool keyState(KeyCode k)=0;
  // —— 配置/查询 ——
  virtual bool setTargetWindow(void* nativeHandle)=0;               // 见 §5
  virtual void  setMoveDurationMs(int32_t ms)=0;                    // 0=瞬移;>0 拟人插值
  virtual void  setMoveSteps(int32_t n)=0;
  virtual void  setKeyDelayMs(int32_t ms)=0;
  virtual bool screenShot(IImageBuffer* imageBuffer)=0;             // 抓帧: bgra8→rgba8+黑屏检测
  virtual bool  screenBounds(vec2i* size)=0;                 // size->x=宽 size->y=高(虚拟屏)
  virtual const char* getLastError()=0;
};
AVOX_EXPORT IInputController* createInputController();               // 调用方 delete
AVOX_EXPORT void* findWindowByName(const char* name);                // 按标题子串查找
```

## 4. 拟人化基类 BaseInputController（src/avox/vision/BaseInputController.hpp）
`IInputController` 公共接口保持最小(跨 DLL 安全),拟人化配置经本基类暴露。调用方 `dynamic_cast<BaseInputController*>` 设置(同 `addTextRecognizerOb` cross-cast 模式)。
```cpp
class BaseInputController : public IInputController {
 public:
  // 拟人化配置(基类直接实现, 子类自动继承)
  void setHumanize(bool on);       // 总开关, 默认 false
  void setJitterSeed(uint32_t seed);// 0=随机; >0=可复现
  void setClickHoldMs(int32_t ms);  // 0=humanize时随机40~90ms; >0=固定
 protected:
  bool humanize = false;
  int32_t clickHoldMs = 0;
  std::mt19937 rng;               // 构造时 random_device 播种, 互斥由子类 mtx 保护
  int32_t jitterMs(int32_t base); // base ± 30%, 下限 1ms; humanize 关时原样返回
  int32_t clickHold();            // humanize 时随机/固定保持时长, 否则 0
  void sampleBezier(...);         // 三次贝塞尔采样 steps 点(含终点)
  void makeControlPoints(...);    // P1@1/3 P2@2/3 垂直偏移 10~30%, clamp 到虚拟屏
};
```
- **贝塞尔轨迹**(humanize + moveDurationMs>0): `P0=当前光标, P3=目标`, P1/P2 随机偏移 + 逐点 ±1px 微抖动(终点不抖保证精确)。
- **自然点击**: 按下后 `clickHold()` 保持再抬起; 双击间隔 `jitterMs(50)`。
- **抖动延迟**: 所有内部 Sleep 走 `jitterMs(base)` = base×0.7~1.3 随机, 下限 1ms。
- **可复现**: `setJitterSeed(seed>0)` 换固定种子 → 同 seed 下轨迹/时序完全一致(回放/压测)。

## 5. 平台实现
| 平台 | 鼠标 | 键盘 | 文本 | 拟人化 | 关键 API | 状态 |
|---|---|---|---|---|---|---|
| Windows | `SendInput` MOUSEINPUT | KEYBDINPUT | `KEYEVENTF_UNICODE` | 贝塞尔+jitter | `GetSystemMetrics` `ClientToScreen` | ✅ 已实现 |
| Linux | X11 `XTestFakeMotionEvent/ButtonEvent` | `XTestFakeKeyEvent` | `XStringToKeysym` | (后补) | 需 X server + `DISPLAY` | ⬜ no-op 占位 |
| macOS | `CGEventCreateMouseEvent`+`CGEventPost` | `CGEventCreateKeyboardEvent` | `CGEventKeyboardSetUnicodeString` | (后补) | 需「辅助功能」 | ⬜ no-op 占位 |
| Android/iOS/WASM | — | — | — | — | — | ⬜ no-op |

`typeText` 与击键不同：直接发 Unicode 码点，绕过键盘布局（中文/日文/任意 IME 文本），Windows 走 `KEYEVENTF_UNICODE`，一步到位。

## 6. 坐标系、窗口与多显示器（统一"坐标面"模型）
- **坐标面 origin**：`setTargetWindow(hwnd)` → 客户区左上角(`ClientToScreen(0,0)`)；`nullptr` → 虚拟屏左上角(`SM_X/YVIRTUALSCREEN`，多显示器时可能为负)。所有用户坐标(moveTo/click/drag/getCursorPos/screenShot)都在该面的**局部坐标**下(原点=面左上，恒 ≥0)：`toScreen = local + origin`，`getCursorPos = GetCursorPos - origin`。
- **screenShot↔click 对齐**：抓帧帧像素 (x,y) 即该面；`click(x,y)` 经 `toScreen` 落到同一物理像素。多显示器/跨屏逐像素对齐，调用方永不接触负坐标。
- **screenBounds**：返回该面尺寸（窗口客户区 / `nullptr`=虚拟屏），与帧尺寸一致。
- **moveBy**：面内增量(=物理增量，平移不变)，不受窗口原点影响。
- **抓帧实现**：`nullptr`→BitBlt `GetDC(NULL)` 虚拟屏；窗口→BitBlt `GetDC(hwnd)` 客户区。GDI BGRA→**RGBA 交换 + alpha 补 255**(避免颜色错位和透明问题) + 黑屏检测(RGB 全 0→false)。
- **DPI 缩放**：`SendInput` 绝对坐标基于物理像素；进程须 Per-Monitor DPI-aware（否则高分屏点偏），属调用方职责。

## 7. 安全与边界（本层职责）
本层是底层原语，**不读配置、不决定使能**；使能/总停/限速归调用方。本层只负责：
- **输入校验**：非法 `MouseButton`/`KeyCode`、`hotkey` 空数组 → false + `getLastError()`。
- **并发互斥**：实例内 `std::mutex`，public 方法 lock，内部 `*Impl` 不 lock（click/drag 组合调用不重入死锁）。
- **无全局态**：每实例独立，`delete` 即净。

## 9. 边界与风险
- **权限**：macOS 辅助功能、Linux X 访问控制；移动端不可行（no-op）。
- **DPI**：高分屏物理/逻辑像素易点偏，调用方须 DPI-aware（§6）。
- **合成输入屏蔽**：UAC 提权窗、部分全屏独占游戏会丢弃合成输入，非本层可解。
- **反作弊**：瞬移/零间隔易被识别，`-humanize` 模式下贝塞尔轨迹 + 随机抖动 + 自然点击保持大幅缓解; 固定种子(`-seed`)可复现。
- **X11 退场**：Wayland 下 XTest 不通，需后补 `libei`/`ydotool`(uinput) 路径。
