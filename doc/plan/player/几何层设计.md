# 几何层（线/矩形/点/圆）设计

## 1. 目标

Vulkan 层 `VkGeometryLayer`，在视频帧上叠加绘制线段、矩形、点、圆。
复用 `VkFontLayer` 的 "CPU 光栅化到小 canvas(R8) → upload → GPU sampler 双线性混合" 管线。

## 2. 核心机制：线宽渐变交给 GPU 双线性（CPU 不算线宽）

关键原则：**线宽（粗细）的 0→1 渐变完全由 GPU 采样器双线性放大产生，CPU 不算。** CPU 只画固定宽度的形状（0/255 主体），GPU 双线性把 255 扩散成渐变带，shader `step(阈值)` 在带上切等值线控宽。

```
CPU: canvas(帧/tscale, R8) 上画形状（0/255 主体 + 曲线/斜边边缘 AA）→ upload
GPU: LINEAR sampler 双线性放大 → 产生 1.0→0 渐变带（线宽控宽用）
     step(阈值, α) 硬切：≥阈值 →1 全合并(不透明)，<阈值 →0 丢弃
```

- canvas 上线 2px core（255），放大 S=4 倍后横截面是约 6 帧像素的渐变带（中心≈1.0 → 边缘→0）。
- shader 设阈值 τ：**τ 越低线越宽、τ 越高线越细**——在渐变带上选等值线，约 S 档可选，无半透明。

| 阈值 τ | 效果 |
|--------|------|
| 0.1 | 最宽（渐变带几乎全过）|
| 0.5 | 中等 |
| 0.9 | 很细（只切到中心）|
| >0.95 | 消失 |

> 注意区分两种渐变（用途不同，别混）：① **线宽渐变**（本节，控粗细）——GPU 双线性产生，CPU 不算；
> ② **边缘 AA 渐变**（第 4 节，消锯齿）——只对圆/斜线，CPU 在形状边界写 1px 渐变 alpha，
> 因为轴对齐的双线性平滑不掉对角阶梯，需 CPU 预算子像素覆盖率把阶梯角落填平。

## 3. 关键前提：sampler 必须是 LINEAR

`VkTexture::createSampler(bool bLinear)` 曾有 bug——忽略 `bLinear` 写死 `VK_FILTER_NEAREST`。
导致 canvas 上 0/255 经最近邻取出来还是 0/1，没有渐变，阈值在 (0,1) 间切结果完全一样（"0~1 没任何变化"）。
已修复为按 `bLinear` 选 LINEAR/NEAREST。**任何依赖小 canvas 放大渐变的层，必须确认 sampler 真的是 LINEAR。**

## 4. 图元光栅化（CPU）

canvas 空间下写 255（内部/core）或 0，max 混合（图元重叠取亮）。**曲线/斜边的边缘写 1px 渐变 alpha 做 AA**（直线/矩形边不需要）：

- **点（实心 disc）**：内部（sdf < −1）写 255；边缘带（sdf −1~1）按距圆周距离写渐变 alpha
- **圆环**：环带内按到圆周距离写渐变 alpha（sdf 0→1 映射 α 1→0）
- **线段**：core（到线段距离 ≤1）写 255；两侧 1px AA 渐变（1<dist<2）
- **矩形填充**：内部全 255（直边，无 AA）
- **矩形描边**：4 条线段（同线段 AA）

**为什么曲线/斜线需要 AA，直线不需要**：canvas 分辨率低（480×270），曲线周长/斜边只有少量像素近似，0/255 二值化后锯齿明显；轴对齐的双线性放大只平滑 x/y 方向，平滑不掉对角阶梯。边缘写渐变 alpha = 预计算子像素覆盖率，双线性放大后阶梯角落被填平，圆变圆、斜线变直。直线本身无锯齿，纯 255 即可。

坐标用帧归一化 [0,1]，内部 `× canvasW/H`。**点/圆 radius 以 1080p 帧像素为基准**，内部 `/scale` 转 canvas px（dpiScale 自动消去：`radius×dpiScale/tscale = radius/scale`），所以 720p/1080p/4K 下圆的视觉比例一致。
CPU 只扫各图元包围盒，小 canvas 下开销可忽略。

## 5. blend shader（drawShapeBlend.comp）

```glsl
float a = textureLod(inTex2, uv, 0).r;     // canvas LINEAR 采样（GPU 产生渐变）
float k = step(ubo.threshold, a);          // 硬切：≥τ →1，<τ →0
color.rgb = mix(color.rgb, ubo.fcolor, k); // k=1 全替换(不透明)，k=0 不变
```

UBO = `{ r, g, b, threshold }`（std140，4 个 float）。descriptor：[0]视频帧 storage_image、[1]canvas combined_image_sampler、[2]输出 storage_image、[3]UBO。

## 6. 双 dirty 标志（避免每帧重算）

GeometryRender 持有图元+设置（用户线程写，mutex 保护），VkGeometryLayer 在 render 线程按 dirty 取快照：

- **rasterDirty**（计算密集）：`clear/draw*/setScale/setLayer` 置位 → `onPreFrame` 里 rasterize + upload
- **paramDirty**（廉价）：`setColor/setThreshold/setLayer` 置位 → 仅 `updateUBO`

两者皆空则跳过。图元不变时零光栅化开销。

## 7. API 与集成

`IGeometryLayer`（定义在 `VkExport.h`）：`setColor / setScale / setThreshold / clear / drawPoint / drawLine / drawRect / drawCircle`。
C 导出：`enableRenderGeometry(ISurfaceRender*) / disableRenderGeometry(ISurfaceRender*)`。

VkVideoRender 集成（仿 FontLayer）：
- `enableRenderGeometry`：`setEnable(true)` + `bResetFlag`，返回 GeometryRender*
- `disableRenderGeometry`：`setEnable(false)` + `setLayer(nullptr)` + `bResetFlag`——对象常驻，仅让 VkGeometryLayer 下次重建时不接入执行链（在 ISurfaceRender 释放时自动回收）
- `vaildAndInitGraph`：`enabled()` 则 `addNode<VkGeometryLayer>` + `setSource` + `setLayer`，接到 graph 链尾

## 9. 与 FontLayer 的差异

- FontLayer canvas 里存字形 alpha（自带渐变），NEAREST 也能用；几何层 core 写 0/255、曲线/斜边边缘写 AA 渐变，**必须 LINEAR**。
- FontLayer 用 `bNeedUpdate` 增量 blit；几何层用双 dirty（raster/param）。
- 几何层无字形缓存，直接距离判定写 255。
- 线宽由 shader UBO 的 `threshold` 全局控制（同一 dispatch 内所有线宽一致），不是 CPU per-shape 参数。
- 可与 FontLayer 共存于同一 PipeGraph，各自独立 canvas + dispatch。
