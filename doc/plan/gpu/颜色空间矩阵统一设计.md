# 颜色空间矩阵统一设计（ColorSpace）

## 1. 背景

SourcePlayer 录屏的 MP4 在饱和绿/蓝图标区出现红蓝条，预览正常。

- 预览：BGRA → GPU 显示，纯 RGB，不进 YUV → 正常。
- 录制：BGRA → `rgba2yuv` shader → 编码 → 文件，问题在 YUV 段。

根因：`rgba2yuvV1.comp` 出的是 **full range BT.601** YUV，但 `FFVEncoder` **没打 `color_range/colorspace` 标签**，播放器默认按 limited(16–235) 解释 → 饱和色裁切偏色，叠加 4:2:0 色度混叠成彩色条纹。

同一套系数还在 GLSL×8 + HLSL×2 + CPU 复制约 10 处。根因是 shader 颜色数学与 encoder 标签是两套来源，必然漂移。

## 2. 目标

单一真相源：C++ 一处定义规范+量程 → 矩阵下发 shader（只做 `mat×vec`），同源映射成 encoder tag。消除重复，支持 BT.601/709、full/limited。

## 3. 架构

```
           ColorSpaceDesc { standard, range }      ← 唯一真相源 (C++)
                       │
         ┌─────────────┴─────────────┐
         ▼                           ▼
 buildRgbToYuv/buildYuvToRgb    mapRange/mapSpace
 → Mat4x4f → UBO                → codecCtx color_range/colorspace...
 shader: out = M × vec4(in,1)   FFVEncoder SPS VUI 正确标注
```

## 4. ColorSpace.hpp

```cpp
// src/avox/video/ColorSpace.hpp   只依赖 avox/AvoxMath.h，不碰 ffmpeg
enum class YuvStandard { bt601, bt709, bt2020 };
enum class YuvRange    { full, limited };
struct ColorSpaceDesc { YuvStandard standard = YuvStandard::bt601;
                        YuvRange range = YuvRange::full; };
// 归一化 [0,1] 仿射矩阵(平移在第4列), UV±0.5 折进偏移列
Mat4x4f buildRgbToYuv(const ColorSpaceDesc& cs);  // vec4(R,G,B,1)→(Y,U,V)
Mat4x4f buildYuvToRgb(const ColorSpaceDesc& cs);  // vec4(Y,U,V,1)→(R,G,B)
```

## 5. 矩阵系数

full range（UV 居中 0.5），正向 `(Y,U,V) = M·(R,G,B)`：

| 规范 | Y | U | V |
|---|---|---|---|
| BT.601 | `.299 .587 .114 0` | `-.16874 -.33126 .5 +.5` | `.5 -.41869 -.08131 +.5` |
| BT.709 | `.2126 .7152 .0722 0` | `-.09991 -.33609 .436 +.5` | `.615 -.55861 -.05639 +.5` |

反向同理（BT.601：R 行 `1 0 1.402 -.701`；G 行 `1 -.34414 -.71414 +.529`；B 行 `1 1.772 0 -.886`）。
limited = full 结果再 `Y·219/255+16/255`、`UV·224/255+0.5`，C++ 合成一张矩阵下发。

> BT.601 full 必须与现状 `rgba2yuvV1.comp` 逐位一致，兼容既有录像。

## 6. Shader 改造

删 `rgb2Yuv`/`yuv2Rgb`，从 UBO 读 `mat4` 做一次乘法；各格式打包/解包逻辑（nv12/yuv420p/yuv422/10bit）不动；按 `YuvType` 选 V1~V4 的机制不变。

```glsl
layout (binding = 3, std140) uniform ColorMat { mat4 mat; } cmat;  // 独立 binding 避开 std140 对齐
vec4 yuva = cmat.mat * vec4(rgba.rgb, 1.0);
```

矩阵字节序沿用 `colorMatrix.comp` 已验证的约定，以它为基准对拍（最易踩坑点）。

## 7. Layer / 编码器 / DX / CPU

- `VkRGBA2YUVLayer/VkYUV2RGBALayer`：新增 `setColorSpace()`，`onInitLayer` 里调 `buildRgbToYuv/buildYuvToRgb` 写入 binding=3 UBO。默认 `{bt601,full}` 不改现状。
- `FFVEncoder::onPreEncoder`：`ColorSpaceDesc` 经 `VideoDesc` 流入，映射成 `codecCtx->color_range/colorspace/...`，替换硬编码 tag。
- `Dx11VideoYuv.cpp`/`Dx11CSVideoRender.cpp`/`ImageBuffer.cpp`：矩阵由 C++ 注入，收敛重复。

## 8. 量程策略

| 编码器 | range | 说明 |
|---|---|---|
| 软编 libx264/x265 | full + JPEG tag | 屏幕内容不损失，正确支持 tag |
| QSV / AMF | limited（默认） | 无视 JPEG tag，shader 出 limited 兜底 |
| NVENC | full + tag | 支持 full |

## 9. 落地（每阶段默认值不变、零回归）

0. **最小修复**：仅给 `FFVEncoder` 补 full-range BT.601 tag（<10 行），录一段验证红蓝条归因。
1. `ColorSpace.hpp/.cpp` + BT.601 full 对拍单测。
2. shader + Layer 改 mat×vec，对拍阶段 1。
3. encoder 同源 tag + 量程分流。
4. DX11/CPU 收敛。

## 10. 验证

矩阵对拍（C++ vs 现状 shader，纯绿/蓝/红/灰阶误差=0）；转置检查（对拍 `colorMatrix.comp`）；`ffprobe color_range/color_space` 与 `cs` 一致；VLC 与 avox 播放均无红蓝条；dump 一帧 U/V 平面无错位。
