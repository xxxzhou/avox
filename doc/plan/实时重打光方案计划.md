# 播放器实时重打光(Relight)方案计划

> 目标:在播放器里对视频帧做**虚拟光源实时打光**——光源跟随鼠标,阴影/高光按画面各深度层次正确变化。
> 参照对象:PIXLRelight(<0.1s/帧)、Clipdrop Relight 的交互效果。
> 约束:集显(AMD 780M / Intel Arc iGPU 档)实时、不训练、用现成权重、C++/Vulkan 集成。

## 1. 核心结论与路线

把"重的理解"和"轻的合成"拆开,**不在交互路径上跑 AI**:

```
[贵·低频] 解码帧 → 单目深度模型(Depth Anything V2-Small) → 深度图缓存
                → 法线图(GPU 从深度差分导出,不要第二个模型)
[便宜·每帧] 当前帧 + 缓存(法线/深度) + 光源 UBO → Phong 着色 pass → 上屏
```

拖灯时只有最后一步在跑(shader 乘加,<1ms),核显零压力。AI 部分走 **CPU EP**(不是 DirectML):推理频率低(静态机位背景基本只需一次),桌面 CPU 多线程 50~150ms 可接受,且避开 D3D12↔Vulkan 互操作的坑。

## 2. 复用现有设施

| 现有模块 | 用途 |
|---|---|
| `src/avox/vision/` IONNXSession / OnnxSessionCache | 跑 Depth Anything V2-Small ONNX,CPU EP |
| `src/avox_vulkan/layer/` VkPipeGraph/VkLayer | 新增 VkRelightLayer 接入渲染链(仿 quality/ 下各层) |
| `src/avox_vulkan/geometry/` 双 dirty 模式 | rasterDirty(估深度+传图)/ paramDirty(拖灯只更新 UBO) |
| `src/avox_analysis/` YOLO26-pose 人框 | 前景 ROI:M3 里运动区域动态重估深度 |
| `assets/models/` 目录约定 | 存 `depth_anything_v2_small.onnx`(社区有权重,~25M 参数) |

## 3. 性能预算(780M 档核显,CPU EP)

| 环节 | 耗时(量级) | 频率 |
|---|---|---|
| DA-V2-Small @384~518px,CPU 多线程 | 50~150ms | 场景变化时 / 每 N 秒 / 前景出现 |
| 法线提取(GPU 差分 pass) | <1ms | 深度更新时 |
| 光照合成 dispatch | <0.5ms | 每帧 |
| 内存增量 | 约 100~200MB | 模型 + 两张缓存纹理 |

## 4. 关键设计点

- **法线从深度导**:shader 里对深度图做 Sobel 差分转法线,省一个模型、少一份失配风险。
- **静态机位假设即缓存策略**:监控流背景几何不变,深度估一次长期复用;场景切换检测(镜头切变)或相机 PTZ 转动才触发全幅重估。
- **失效兜底**:夜间红外/大块高光/严重压缩画面上深度可能崩——退化策略为法线全置朝向相机(N·L 平面光),观感退化为简单方向光但不闪黑;严重低质画面建议先过已有的画质增强链(VkQEnhance/去块)再估深度。
- **光照模型 v1**:点光 + 环境项 + Lambert 漫反射 + Blinn-Phong 高光 + 按深度的距离衰减;光源 z 取鼠标处深度 × 抬升系数。像素本体不做 albedo 分解(v1 直接当反照率,阴影烘焙残留可接受,真实 demo 也这么简化)。

## 5. 里程碑

### M1:静态图片最小验证(独立工具,不碰播放器)
samples 下仿 vklayertest 加个小工具:载入一张图 → 估深度 → 拖灯看效果。验收:鼠标跟手无卡顿,层次感达到 PIXLRelight 截图的七八成。
产出:`RelightDemo`,确认模型选型与阈值手感。工作量:2~3 天。

### M2:接入播放器 Vulkan 渲染链
新增 `src/avox_vulkan/relight/`:`VkRelightLayer{hpp,cpp}`(取当前帧 + 缓存纹理,relightLight.comp 合成)、`RelightRender{hpp,cpp}`(双 dirty 快照)、`glsl/source/relightNormal.comp`;C 导出仿 `enableRenderGeometry` 加 `enableRenderRelight(ISurfaceRender*)`;窗口鼠标事件 → 归一化坐标 → paramDirty。
验收:监控流上开/关功能,开启后帧率无明显下降,拖灯流畅。工作量:4~5 天。

### M3:前景联动(YOLO ROI 动态重估)
利用 avox_analysis 人框:前景区域裁剪送深度模型回填缓存,人走过时光影跟随;频率限流(ROI 小,10~20ms 级)。
验收:行人经过时不出现"平贴"伪影闪烁。工作量:2~3 天。

### M4:增强项(按需)
基于深度图光线步进的投影阴影;DirectML EP(D3D12)加速评估——若做需解决与 VkContext 的纹理共享或走 readback;与曝光/LUT 统一联调(对齐"颜色空间矩阵统一"既有约束)。工作量:各 1~2 天。

## 6. 效果边界(如实)

能做到方向光/点光的漫反射+高光+层次正确的七八成观感;做不到全局效果(间接反弹、半影软阴影,M4 后部分补齐);物体快速移动瞬间其周边 shading 有 1~2 个刷新周期的滞后(M3 缓解)。与扩散式 IC-Light 是两条路线:本方案保实时,IC-Light 类适合离线加工工具,互不替代。

## 7. 风险

| 风险 | 对策 |
|---|---|
| 监控压缩画面深度不稳 | 前置增强链;多帧投票取中值再出缓存 |
| ONNX CPU 推理偶发毛刺 | 放独立线程,生产者-消费者,主链路永不阻塞 |
| 不同机位分辨率差异 | 深度纹理独立于显示分辨率,统一归一化坐标 |
