## 依赖安装 (Ubuntu 24.04)

```bash
sudo apt install build-essential cmake python3 ninja-build pkg-config \
  libx11-dev zlib1g-dev libpng-dev libbz2-dev libpulse-dev libva-dev \
  mesa-vulkan-drivers vulkan-tools ffmpeg pulseaudio-utils
```

FFmpeg 用 `3rdparty/library/linux/ffmpeg` 预编译包 (构建方法见 `script/ffmpeg/build_ffmpeg_linux.sh`), 不用系统包。

## WSL 注意事项 (重要)

- **swap**: 默认 `.wslconfig` 常见 `swap=0`, 编译高峰(大 TU 并行 g++)会把 16G 内存打穿触发 OOM-killer 集体击杀, 表现为构建中途无声消失。临时方案: `wsl -u root` 下 `fallocate -l 16G /swapfile && mkswap /swapfile && swapon /swapfile`; 根治: `.wslconfig` 里 `swap=16GB`。并行度可用 `CMAKE_BUILD_PARALLEL_LEVEL` 压低。
- **构建目录必须在 ext4** (`~/avox`), 别在 `/mnt/d` 上编译 (9p IO 慢一个数量级)。同步源码可用 `cp` 走 `//wsl$/Ubuntu/home/<user>/avox/`。
- **WSLg 显示**: `DISPLAY=:0` 即 XWayland, 窗口直接出现在 Windows 桌面; 截窗验证可用 `xwd -name avox | ffmpeg -i pipe:0 out.png` (root 抓取 BadMatch, 必须按窗口抓)。
- **验证 Vulkan**: `vulkaninfo --summary` 应看到 dzn(Paravirtualized D3D12) 或 lavapipe(CPU)。

## 构建与运行

```bash
cd ~/avox && python3 build_linux.py          # 产物 build/linux/avox/install/x86_64/
ctest --test-dir build/linux/avox            # 单测
# 窗口播放 (宿主建窗口):
cd build/linux/avox/install/x86_64 && LD_LIBRARY_PATH=. ./linuxtest <url或文件>
# 播放回归矩阵离线子集 (无 ZLM, CI 用):
python3 script/testenv/play_regress.py --offline
```

离线子集在 Linux 上额外跳过 `shot`/`yuvout-h264-soft`(需原生渲染器) 与 `rec-transcode-*`(需视频编码器), 见 `script/testenv/play_regress.py` 的 `LINUX_OFFLINE_SKIP`。
