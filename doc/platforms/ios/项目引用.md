# 项目引用

要让 /Volumes/PSSD/work/github/avox/platform/ios/testbed/testbed.xcodeproj 引用 /Volumes/PSSD/work/github/avox/build/ios/avox/avox.xcodeproj 项目，可按以下步骤操作：

1. 打开项目
分别在 Xcode 中打开 testbed.xcodeproj 和 avox.xcodeproj 项目。

2. 添加 avox.xcodeproj 到 testbed.xcodeproj
在 Xcode 中，切换到 testbed.xcodeproj 项目，在项目导航器里右键点击 testbed 项目，选择 Add Files to "testbed"。然后找到并选中 /Volumes/PSSD/work/github/avox/build/ios/avox/avox.xcodeproj 文件，点击 Add。此时 avox.xcodeproj 会出现在 testbed.xcodeproj 的项目导航器中。

3. 设置 Target 依赖
展开 Target Dependencies 部分，点击 + 按钮，选择avox.
在Link Binary With Libraries部分，点击 + 按钮，把install/aarch64/Debug|Release下所有静态库文件添加进来,直接拖入即可.然后对照avox.podspec把系统的frameworks与libraries加入.
MoltenVK.framework需要选择add Other/Files选择install/aarch64/MoltenVK.framework添加,注意嵌入选项设置为 `Embed & Sign`.

4. 配置搜索路径
选择 testbed 项目的 testbed Target，切换到 Build Settings 标签页。
搜索 Header Search Paths，双击该选项，添加 avox 项目头文件所在的目录路径，例如 /Volumes/PSSD/work/github/avox/build/ios/avox/include。
确保路径被设置为 recursive，这样 Xcode 会递归查找该目录下的所有头文件。
在 Build Settings 标签页中，搜索 Library Search Paths。
双击该选项，添加 avox 项目库文件所在的目录路径，例如 /Volumes/PSSD/work/github/avox/build/ios/avox/lib。
同样将路径设置为 recursive。
在 Build Settings 标签页中,搜索Runpath Search Paths.添加@executable_path/Frameworks,找外部frameworks如MoltenVK时使用.

5. 验证引用
在 testbed 项目的代码文件中，尝试引入 avox 项目的头文件并调用其中的函数或类，若编译和运行正常，说明引用成功。示例代码如下：

``` objective-c
ViewController.m
Apply
#import "ViewController.h"
// 引入 avox 项目的头文件
#import "AvplayHeader.h" // 替换为实际的头文件名

@interface ViewController ()

@end

@implementation ViewController

- (void)viewDidLoad {
    [super viewDidLoad];
    // 调用 avox 项目的函数或方法
    // [AvplayClass someMethod]; // 替换为实际的调用代码
}
@end
```

通过以上步骤，testbed.xcodeproj 项目就能成功引用 avox.xcodeproj 项目了。
