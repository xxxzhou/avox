> 骨架: 标题只写 ②多协议 ③WebRTC + 零拷贝直通; ①本地源进功能列表保底。

## 1. Fab (UE, avox-ue)

**Title (EN, ≤80 字符):**
> Low-Latitude Live Video for UE5 — RTSP/RTMP/HLS + WebRTC, HW Decode, Zero-Copy GPU

(定稿再校字符数; "Low-Latency" 若超限用 "Sub-Second Live Video")

**Short desc:**
> Pull RTSP / RTMP / HLS streams and sub-second WebRTC into Unreal Engine with
> hardware decoding and zero-copy GPU passthrough (D3D11 / D3D12 / Vulkan RHI).
> Measured glass-to-glass latency: ~0.7 s over WebRTC.

**Highlights:**
- Sub-second WebRTC (signaling via ZLMediaKit / WHEP), measured 0.7s glass-to-glass
- RTSP / RTMP / HLS / TS pull with hardware decode (H.264 / H.265)
- Zero-copy GPU passthrough to RHI: D3D11 / D3D12 / Vulkan — frames stay in VRAM, no CPU readback
- AvoxMediaPlayer Component/Actor + AvoxGpuInterop; player-only scope (no AI)
- Local file playback (MP4/HLS/TS), play/pause/seek/speed, screenshot, recording
- LGPL FFmpeg 9.0.1 self-built (no fdk-aac), license report included

**Platform 口径 (必须写清):** Windows x64 only (Win64 allowlist)。源码分发, 已验证
UE 5.8.2, LTS 矩阵补充验证中。Android/iOS 不支持。

**素材:** 待录 (编辑器机, run_packagegame 无人值守实录, 不用编辑器 slate 防节流)。

## 2. Unity Asset Store (avox-unity)

**Title:**
> Avox Player — RTSP/RTMP/HLS + WebRTC Streaming, HW Decode, Zero-Copy GPU

**Pitch:**
> Bring live streams into Unity at sub-second latency. Native avox.dll +
> avox_unity.dll bridge (11 runtime DLLs), hardware H.264/H.265 decode, and
> zero-copy GPU path (D3D11 shared texture / Vulkan external memory) straight
> into RenderTexture. WebRTC glass-to-glass measured at ~0.7s.

**Highlights:**
- WebRTC / RTSP / RTMP / HLS / TS / local files
- HW decode H.264 & H.265; zero-copy GPU interop (Vulkan zero-copy, D3D11 copy mode)
- AvoxMediaPlayerComponent: play/pause/seek/speed/volume, events, media info JSON
- Deploy script + runtime DLL whitelist (FFmpeg 63-gen aligned), strict license check
- Third Party Notices: FFmpeg 9.0.1 LGPL self-built

**Platform 口径:** Windows x64 (编辑器 + player); Android so 已打通但非本 SKU;
iOS 未包含。batchmode 验证过 dll 加载/组件创建/软解播放; Vulkan 零拷贝需交互式
人工验证 (已列 checklist)。

**素材:** demo 已有 screenshots; .unitypackage 编辑器手工导出 (唯一手工步)。

## 3. Godot Asset Library (avox-godot, dist 分支)

**Title:**
> Avox Godot Player — RTSP/RTMP/HLS/WebRTC streaming with HW decode & GPU passthrough

**Desc (EN):**
> GDExtension (Godot 4.3+, Vulkan) media player for live and local video.
> MediaPlayer / SourcePlayer / RtcPlayer nodes with media info, events and
> recording. Hardware H.264/H.265 decode, zero-copy GPU passthrough to
> TextureRect, 4-way simultaneous decode wall at 29fps. WebRTC glass-to-glass
> ~0.7s (ZLM signaling / WHEP). Includes demo hub scenes + English quickstart.
> Windows x64 binaries in Release zip (binaries not in git — download Release
> first). Android .so available as add-on; Linux/macOS not supported.

**类目:** Libraries (GDExtension 惯例, 无需 plugin.cfg)。
**安装说明必须放显眼处:** assetlib 条目 → Releases zip (49MB, 自包含含 dll/许可) 或
dist 分支 (仓库根即工程)。
**素材:** 已生成 6 张 (demo/screenshots): hub / local_player / live_stream /
record_demo / video_wall 均为真实渲染抓帧; **mic_subtitle 场景缺失** (mic_subtitle.tscn
不存在, 现为兜底图, 需补场景或从列表去掉)。
