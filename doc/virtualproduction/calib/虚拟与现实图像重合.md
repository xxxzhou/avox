# 虚拟与现实图像精准重合

对精度要求比较高的XR场景中,在虚拟摄像机与真实摄像机位置重合后,需要真实图像与虚拟图像能完全重合,虚拟摄像机产生的图可以看成是一种中心在(0.5,0.5)并且没有任何畸变的图,而现实中摄像机针对畸变都有比较完善的处理,但是如何保证虚拟摄像机与真实摄像机的中心位置重合了?毕竟就算比较好的像机,只有0.005个偏移,在1080P的图像中,也有0.005x1920差不多5个像素偏移,在对焦距离比较近的情况可能不太明显,但是如果在对焦距离达到10m后,XR拍摄与LED的距离在10m上还是很常见的,假定FOV大约是45度左右,那么当时图像对应的实际宽度也有10m,对应5个像素有2.5厘米左右的偏移了.在XR中,这么大的偏移足够导致图像完全合不上去了,这还是比较好的摄像机,还有中心直接有0.2偏移的摄像机,那这种,不用很远,一二米就能看到真实图像与校正后的虚拟图像也合不起来.

可以看到,融合效果都不理想,其第一台摄像机在近处拍摄的图,融合看起来没什么问题,只有在远处才有问题,根据前面中心的想法,我第一想法是把虚拟摄像机的位置根据像素的偏移再偏移下,让虚拟摄像机的位置与真实摄像机的中心匹配上.

首先需要知道每个像素对应真实的大小,我们知道LED每个格子的位置,知道摄像机的位置与朝向,可以近似用如下方法确定对焦距离,先确定摄像机的朝向与对应格子的射线的点积,确定角度最小的格子,然后摄像机与这个格子的距离近似为对焦距离,根据对焦距离确定像素偏移距离.

``` c++
Mat4x4d getLensCenterOffset(Mat4x4d& camPose, const LensModel& lensModel,
                            float distance) {
  // 偏移的像素
  vec2d centerOffset = {lensModel.focalCenter.x - 0.5,
                        lensModel.focalCenter.y - 0.5};
  // 图像长度(对应distance的单位米)
  float widthX = distance / lensModel.focalLength.x;
  // 图像宽度
  float widthY = distance / lensModel.focalLength.y;
  // 偏移的长度
  vec3d offsetPos = {centerOffset.x * widthX, centerOffset.y * widthY, 0.0};
  // 转到相记自身的坐标系
  Mat4x4d ledPose = camPose.inverse();
  // 添加偏移距离
  ledPose.row3.x += offsetPos.x;
  ledPose.row3.y += offsetPos.y;
  // 再转到以标定角点的坐标系下的摄像机位置
  return ledPose.inverse();
}
```

这个算法的结果相对前面拉正了一大部分,但是结果依然不算太好,畸变大的摄像机其边缘部分还是有问题,应该是添加偏移距离这步需要更精细的运算.

虽然结果不太好,但是至少可以确定是中心偏移造成的问题,这个问题在对焦距离比较远的时候还会放大,和同事锐哥与阳哥讨论这个问题,确定另外一种方案,可以尝试在真实图像校正畸变后,选择一块完美以中心(0.5,0.5)的区域,尽量保证选择最大的范围,这里有二个选择,一是确定多少像素就是多少像素,二是把这像素缩放到原大小,考虑到每帧运行,图像大小的改变会导致整个底层GPU计算管线资源全部需要重生成,因此选择选定范围重缩放到原大小.这个过程选择如何选择范围不太好确定,经查实,opencv针对畸变处理类似处理,可以先在畸变处理时,选择生成一个中心在(0.5,0.5)的校正图,并生成一个新的内参矩阵,根据原内参矩阵与新的内参矩阵我们得到原始图与处理图后的UV映射图.

顺便说个坑,直接应用图像反畸变是不对的,就算中心在(0.5,0.5),一定要确定最后处理后的图对应的新的摄像机内参,其虚拟摄像机需要应用这个内参重新确定FOV.

先看二个摄像机应用取真实图像以中心(0.5,0.5)的区域里的的效果.



可以看到,这个结果比较好,但是对比上面实现,可以发现有效像素比移动虚拟摄像机的要少一些(二者用的同一alpha),有兴趣的话,可以看下面的具体实现.

``` C++

// 如果用于XR混合虚拟图像,需要把center设置为true,选择和虚拟图像一样中心是0.5/0.5无畸变的理想图,虽然选择的范围会更小
LensModel getDistortLensModel(const LensModel& lensModel, float alpha,
                              bool center) {
  LensModel destModel = lensModel;
  if (lensModel.imageSize.x == 0 || lensModel.imageSize.y == 0) {
    logMessage(LogLevel::warn,
               "getDistortLensModel lensModel must have corrert imageSize");
    return destModel;
  }
  // 摄像机内参
  cv::Mat cameraMatrix;
  // 畸变系数
  cv::Mat distCoeffs;
  cv::Size imageSize(lensModel.imageSize.x, lensModel.imageSize.y);
  lensModelToCV(lensModel, cameraMatrix, distCoeffs);
  // 得到校正畸变后的新摄像机内参
  cv::Mat newCameraMatrix = cv::getOptimalNewCameraMatrix(
      cameraMatrix, distCoeffs, imageSize, alpha, imageSize, nullptr, center);
  lensCVToModel(newCameraMatrix, distCoeffs, lensModel.imageSize, destModel);
  return destModel;
}

// 根据原内参与目标内参得到,UV->校正畸变UV,下面链接讲到如果用这种关系可以畸变,也可反畸变
// https://www.unrealengine.com/zh-CN/tech-blog/camera-calibration-distortion-simulation-and-correction-in-ue4
bool getDistortBuffer(const LensModel& srcLensModel,
                      const LensModel& destLensModel, IImageBuffer* xMap,
                      IImageBuffer* yMap) {
  if (srcLensModel.imageSize.x == 0 || srcLensModel.imageSize.y == 0) {
    logMessage(LogLevel::warn,
               "getDistortBuffer lensModel must have corrert imageSize");
    return false;
  }
  ImageFormat format = {};
  format.width = srcLensModel.imageSize.x;
  format.height = srcLensModel.imageSize.y;
  format.imageType = ImageType::r32f;
  xMap->setImageFormat(format);
  yMap->setImageFormat(format);
  // 畸变UV映射图
  cv::Size imageSize(srcLensModel.imageSize.x, srcLensModel.imageSize.y);
  cv::Mat xMapMat(srcLensModel.imageSize.x, srcLensModel.imageSize.y, CV_32FC1);
  cv::Mat yMapMat(srcLensModel.imageSize.x, srcLensModel.imageSize.y, CV_32FC1);
  // 摄像机内参
  cv::Mat srcCameraMatrix, destCameraMatrix;
  // 畸变系数
  cv::Mat srcDistCoeffs, destDistCoeffs;
  lensModelToCV(srcLensModel, srcCameraMatrix, srcDistCoeffs);
  lensModelToCV(destLensModel, destCameraMatrix, destDistCoeffs);
  // initInverseRectificationMap添加畸变
  cv::initUndistortRectifyMap(srcCameraMatrix, srcDistCoeffs, cv::noArray(),
                              destCameraMatrix, imageSize, xMapMat.type(),
                              xMapMat, yMapMat);
  // 复制出结果
  memcpy(xMap->getPointer(), xMapMat.data, getImageSize(format));
  memcpy(yMap->getPointer(), yMapMat.data, getImageSize(format));
  return true;
}
```

移动真实的画面匹配虚拟的画面中心,对真实的画面有损失,如果介意真实画面的损失,那么移动虚拟的画面去匹配真实的中心是否可行,先看结果.



可以看到,相比上一种方案,移动虚拟UV对真实画面的损失比较小,但是移动的边缘部分现只有真实画面(有没同学知道,UE里的USceneCaptureComponent2D如何改里的FMinimalViewInfo里的OffCenterProjectionOffset,应该能达到同样效果,并且边缘部分也能融合.)有兴趣的话,可以看下面的具体实现.

``` glsl
#version 450

layout(local_size_x = 16, local_size_y = 16) in; // gl_WorkGroupSize

layout(binding = 0) uniform sampler2D inSampler;
layout(binding = 1, rgba8) uniform image2D outTex;

layout(std140, binding = 2) uniform UBO {
  float leftOffset;
  float topOffset;
  float x;
  float y;
  float z;
  float w;
}
ubo;

void main() {
  ivec2 uv = ivec2(gl_GlobalInvocationID.xy);
  ivec2 size = imageSize(outTex);
  if (uv.x >= size.x || uv.y >= size.y) {
    return;
  }
  vec2 suv = (vec2(uv) + vec2(0.5f)) / vec2(size) +
             vec2(ubo.leftOffset, ubo.topOffset);
  vec2 clampedUV = clamp(suv, vec2(0.0), vec2(1.0));
  // UV是否越界
  vec2 isOutside = step(suv, vec2(0.0)) + step(vec2(1.0), suv);
  vec4 color = textureLod(inSampler, clampedUV, 0);
  // 
  vec4 fillColor = vec4(ubo.x,ubo.y,ubo.z,ubo.w);
  vec4 result = mix(color, fillColor, dot(isOutside, vec2(1.0)));  
  imageStore(outTex, uv, result);
}
```

使用vulkan的Compute shader调用GPU处理,上面是针对虚拟画面的像素移动,下面是使用UV映射图校正畸变.

``` glsl
#version 450

layout (local_size_x = 16, local_size_y = 16) in;// gl_WorkGroupSize

// ADDMAP 相当于原图UV添加MAP后,如添加畸变,反正则去畸变
layout (binding = 0) uniform sampler2D inSampler;
layout (binding = 1) uniform sampler2D inXSampler;
layout (binding = 2) uniform sampler2D inYSampler;

layout (binding = 3, rgba8) uniform image2D outTex;

layout (std140, binding = 4) uniform UBO {
    int mapWidth;
    int mapHeight;
} ubo;

void main(){
    ivec2 uv = ivec2(gl_GlobalInvocationID.xy);
    ivec2 size = imageSize(outTex);  
    if(uv.x >= size.x || uv.y >= size.y){
        return;
    }    
    vec2 suv = (vec2(uv)+vec2(0.5f))/vec2(size);
    float xalpha = textureLod(inXSampler,suv,0).r;  
    float yalpha = textureLod(inYSampler,suv,0).r;  
#if ADDMAP 
    // 添加畸变(在正常的图取正常UV的颜色放入畸变UV图上) distort
    // 畸变UV做为输出,很难处理,现参考UE4做法(近似正常,小计算量)
    vec2 mapUV = (vec2(xalpha,yalpha)+vec2(0.5))/vec2(ubo.mapWidth,ubo.mapHeight);
    vec2 offsetUV = suv - mapUV;
    vec4 uncolor = textureLod(inSampler,suv + offsetUV,0); 
    imageStore(outTex,uv,uncolor);
#else
    // 去除畸变(在畸变图上取对应畸变UV的颜色放入正常UV图上) undistort
    vec2 mapUV = (vec2(xalpha,yalpha)+vec2(0.5))/vec2(ubo.mapWidth,ubo.mapHeight);
    vec4 uncolor = textureLod(inSampler, mapUV,0);      
    imageStore(outTex,uv,uncolor);     
#endif  
}
```
