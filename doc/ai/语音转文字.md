## 方案演进过程

### 语音识别：从 Whisper 到 sherpa-onnx

最初使用 Whisper 模型，但中文识别准确率不理想，且 Whisper 原生为离线架构，流式体验不佳。后来切换到 sherpa-onnx 框架，采用**双模型策略**：
- 实时场景（直播/通话）：使用 Paraformer 流式模型，仅支持中英双语，延迟低
- 视频播放场景：使用 SenseVoice 离线模型 + VAD 切句，支持中日英韩多语言，准确率更优

### 翻译：从 CTranslate2 到 ONNX Runtime 到 HTTP 云翻译

初期尝试 CTranslate2 推理框架，但跨平台编译配置复杂，各平台特性不统一。后迁移到 ONNX Runtime + SentencePiece 分词的统一方案。由于本地小模型翻译效果有限，现已实现 **HTTP 云翻译**（腾讯云翻译API），效果更佳。

| 方案 | 延迟 | 效果 | 语言支持 |
|------|------|------|------|
| ONNX 本地翻译 | ~100ms-2s(文本长度) | 一般 | 日语→中文 |
| HTTP 云翻译 | ~300ms | 优秀 | 多语言→多语言 |

系统优先尝试 HTTP 云翻译，失败后自动降级到 ONNX 本地翻译。

腾讯云翻译API申请流程，先在 [腾讯云官网](https://cloud.tencent.com/) 注册账号并完成实名认证，然后进入 [机器翻译控制台](https://cloud.tencent.com/document/product/551) 开通服务（首次有免费额度），最后在 [访问密钥页面](https://console.cloud.tencent.com/cam/capi) 创建 SecretId 和 SecretKey。配置到 AvaPlayer 语音识别设置界面即可使用。

## 核心实现

播放器基于标准架构：独立视频与音频解码线程，独立的音视频包/帧队列，音频与视频各有独立渲染线程并通过时钟同步。在此基础之上，将音频解码后的数据分流到识别链路，实现识别/翻译字幕与画面的精确同步。

### 双模型策略

| 场景 | 模型 | 模式 | 延迟 |
|------|------|------|------|
| 直播/通话 | Paraformer 流式 | streaming | ~200ms |
| 视频播放 | SenseVoice + VAD | ptsSync | ~1s |

流式识别仅支持中英双语，离线识别支持中日英韩多语言，且可开启翻译。

### PTS 同步机制

视频播放场景下，识别+翻译合计延迟约 1-2 秒，但字幕必须按原始 PTS 显示，不能因识别延迟导致与画面错位。

**数据流**：

```
音频解码线程 ──┬──> frameQueue (4秒缓冲) ──> 音频渲染线程
                │
                └──> 识别线程 (audioStt->load())
                        │
                        ▼ resultQueue
                   翻译线程 (SubtitleAsr::onRunTask)
                        │  翻译器 translator->translate()
                        ▼
                      subtitleQueue
                            │
                            ▼ (渲染线程按 PTS 查找字幕)
                     画面渲染线程 getCurrent(pts)
```

音频解码后同时送入两个独立队列：渲染帧队列和识别队列。

**关键做法**：
- 音频渲染帧队列扩大至 4 秒缓冲，使播放时钟迟于识别进度
- PTS 在整条链路精确透传：解码 → 重采样 → VAD 切分 → SenseVoice 识别 → 标点切分 → 翻译 → 字幕队列
- 渲染时根据当前播放时钟，通过二分查找在字幕队列中精确匹配 PTS
- seek 后 PTS 基准重置，所有队列同步清空

streaming 模式无需 PTS 同步，采集的音频直接送入识别线程，实时显示。

### 多线程协作

4 条独立线程协同工作：
- **音频解码线程**：解码后将音频帧同时送入渲染队列和识别队列
- **识别线程**：`audioStt->load()` 启动，消费识别队列中的音频帧，输出识别结果到 resultQueue
- **翻译线程**（`SubtitleAsr::onRunTask`）：消费 resultQueue，按需加载翻译器，调用 `translator->translate()` 翻译后入 subtitleQueue。翻译线程的前提是识别线程已开启
- **画面渲染线程**：按播放时钟从 subtitleQueue 中查找匹配 PTS 的字幕
- 锁粒度控制在关键队列操作上，避免过粗影响性能
- 识别队列满时丢弃旧数据而非等待，渲染队列满时阻塞
- 字幕队列按 PTS 滑动清理历史数据
- 线程启停和销毁顺序严格控制，防止死锁

### 音频格式转换

输入音频格式各异（44.1k/48k、立体声/单声道、int16/float32），但 sherpa-onnx 接受 `16kHz mono float`固定格式。通过 `AudioReshaper` 统一处理重采样、声道合并、格式转换，输出固定时间对齐帧。

## 关键问题解决

### VAD 段过长导致字幕延迟

SenseVoice 离线识别依赖 VAD（Silero）切句，但连续 speech 之间停顿较短时，VAD 不会切分，导致多个句子合并成一段，出现 10 秒以上的长段。识别完这么长的段才输出一次结果，字幕延迟严重。

**解决**：在 VAD 输出后、送入识别前，增加强制切分逻辑。设定单段最大长度 5 秒，超过则按 5 秒强制切分，保证识别结果及时产出。

### PTS 漂移与对齐

VAD 切分和识别过程中，如果单纯按采样数累加计算 PTS，长时间播放后会产生累积误差，导致字幕与画面逐渐错位。

**解决**：在 `SherpaAudioStt` 中维护 `streamBasePts` 和 `totalStreamSamples`，每接收一帧时检测实际 PTS 与期望 PTS 的偏差，超过 500ms 时重新校准基准，消除累积误差。

## 代码实现

### 音频分流（解码后分别入队）

音频解码线程输出一帧后，将同一份数据分别推入渲染队列和识别队列，两个队列独立消费，渲染队列长延迟高，识别队列短，延迟低，渲染队列满了阻塞，识别队列满了丢弃老的：

```cpp
void AudioTrack::onDecode(const AvoxAFrame& frame) {
    // 1. 解码后的帧继续走正常渲染流程（入音频渲染队列）
    // ... 数据写入 curFrame，凑满后送入音频渲染器

    // 2. 同步送入识别链路（携带原始 PTS）
    if (subtitleView) {
        subtitleView->inputSpeech(frame.buffer， frame.pts);
    }
}
```

### AudioReshaper 初始化与重采样

输入格式各异，统一转换为 sherpa-onnx 要求的 `16kHz mono float`，输出固定 100ms 对齐帧：

```cpp
void SherpaAudioStt::setAudioDesc(AudioDesc desc) {
    srcDesc = desc;
    outDesc = desc;
    // 强制转换为目标格式
    outDesc.format = AVOX_AUDIO_FLT;   // float
    outDesc.channels = 1;              // mono
    outDesc.sampleRate = 16000;        // 16kHz
    frameMs = 100;                     // 100ms 一帧
    initConfig(srcDesc， outDesc);
}

void SherpaAudioStt::recognize(AvoxData data， int64_t pts) {
    AvoxAFrame frame = { data， pts };
    AudioReshaper::process(frame);  // 重采样后回调 onProcess() 入队
}
```

### 识别线程消费帧

独立线程从队列取帧，按 100ms 粒度送入识别引擎：

```cpp
void SherpaAudioStt::onRunTask() {
    initEngine();  // 加载 streaming 或 offline 模型
    while (running()) {
        SherpaFrameItem item;
        if (frameQueue.dequeue(item)) {
            float* samples = (float*)item.data.data();
            int32_t count = item.data.size() / sizeof(float);
            processFrame(samples， count， item.pts);
        } else {
            sleep(10);
        }
    }
}
```

### PTS 漂移校准

每帧检测实际 PTS 与期望 PTS 的偏差，超过 500ms 时重新对齐基准：

```cpp
void SherpaAudioStt::processFrame(float* samples， int32_t count， int64_t pts) {
    if (streamBasePts == 0) {
        streamBasePts = pts;
    } else {
        int64_t expected = streamBasePts + totalSamples * 1000LL / 16000;
        int64_t diff = pts - expected;
        if (diff > 500 || diff < -500) {
            streamBasePts = pts - totalSamples * 1000LL / 16000;
        }
    }
    totalSamples += count;
    offlineEngine->processAudio(samples， count， streamBasePts);
}
```

### 翻译线程（SubtitleAsr::onRunTask）

翻译线程消费识别结果，按需加载翻译器，识别结果入 subtitleQueue 前完成翻译：

```cpp
void SubtitleAsr::onRunTask() {
    audioStt->load();
    while (running()) {
        checkTranslationState();  // 动态加载/卸载翻译器
        SttResult result;
        if (resultQueue.dequeue(result)) {
            processResult(result);
        } else {
            sleep(10);
        }
    }
    audioStt->unload();
}

void SubtitleAsr::checkTranslationState() {
    if (translationEnabled && !translator->ready()) {
        translator->setSourceLanguage(Language::ja);
        translator->setTargetLanguage(Language::zh);
        translator->open();
    } else if (!translationEnabled && translator->ready()) {
        translator->close();
    }
}

void SubtitleAsr::processResult(const SttResult& result) {
  SubtitleItem item = {};
  item.startMs = result.startPts;
  item.endMs = result.endPts;
  item.original = result.text;
  item.language = result.lang;
  item.text = result.text;
  if (translationEnabled) {
    bool btrans = bHttp || (!bHttp && result.lang == Language::ja);
    if (translator && btrans) {
      translator->setSourceLanguage(result.lang);
      const char* translated = translateText(result.text.c_str());
      if (translated && translated[0] != '\0') {
        item.text = translated;
      }
    }
  }
  std::lock_guard<std::mutex> lock(queueMutex);
  subtitleQueue.push_back(item);
}
```

### 字幕查找（二分 + 回退）

渲染时按当前播放 PTS 精确查找字幕，未命中时回退到最近一条，避免延迟导致闪烁：

```cpp
const SubtitleItem* SubtitleAsr::getCurrent(int64_t ptsMs) {
    lock_guard lock(queueMutex);
    int left = 0， right = queue.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        auto& item = queue[mid];
        if (ptsMs >= item.startMs && ptsMs <= item.endMs) return &item;
        if (ptsMs < item.startMs) right = mid - 1;
        else left = mid + 1;
    }
    // 播放时间已超过所有字幕，10 秒内回退显示最后一条
    if (queue.back().endMs < ptsMs && ptsMs - queue.back().endMs < 10000)
        return &queue.back();
    return nullptr;
}
```
