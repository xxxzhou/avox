# 04 依赖关系

## 1. 依赖总览

```
avox.dll (核心 SDK)
├── src/avox_ffmpeg/       → FFmpeg (软解/硬解/解封装/转码)
├── src/avox_zlmediakit/   → ZLMediaKit (RTSP/RTMP/ONVIF)
├── src/avox_vulkan/       → Vulkan/volk (GPU 图像处理)
├── src/avox_freetype/     → FreeType (文字渲染)
├── src/avox_aac/          → faac / fdk-aac (AAC)
├── src/avox_agent/        → cpp-httplib + OpenSSL/BoringSSL (Agent 客户端)
└── 平台模块               → DX11/DX12/MediaCodec/VideoToolbox/EGL/Metal

plugins/*.dll (动态组件)
├── avox_onnx             → ONNX Runtime
├── avox_opencv           → OpenCV
├── avox_cv               → avox_onnx + avox_opencv (水印去除/YOLO)
├── avox_sherpa           → sherpa-onnx + sentencepiece + onnxruntime
├── avox_translation      → onnxruntime
├── avox_webrtc           → WebRTC (含 BoringSSL)
├── avox_avatar           → avox_onnx
├── avox_ocr              → avox_onnx
└── avox_openvino         → OpenVINO
```

## 2. Git 子模块（[.gitmodules](../../.gitmodules)）

**更新子模块：**
```bash
git submodule update --init --recursive
```

## 3. 大型预编译库（avc_library）

从独立的 `avc_library` 仓库（私有，需 `AVOX_LIBRARY_TOKEN`）获取。位于 `3rdparty/library/{platform}/`：

| 库 | 平台 | 用途 |
|----|------|------|
| ONNX Runtime | Windows/Android/iOS | AI 推理引擎（onnxruntime-win/onnxruntime-android/onnxruntime-ios） |
| WebRTC | Windows | WebRTC 推拉流（webrtc.lib） |
| OpenSSL | Windows/Android | 加密/SSL（AVOX_ENABLE_OPENSSL） |

**查找优先级（见 [build_common.py](../../build_common.py)）：**
1. `AVOX_EXTERNAL_LIBRARY_DIR` 环境变量
2. 本地 `3rdparty/library/`
3. 父目录 `avc_library/3rdparty/library/`

**相关下载脚本：** `script/onnx/down_onnxruntime_windows.py`、`script/onnx/down_onnxruntime_android.py`、`script/openvino/extract_openvino.py`

## 5. 插件依赖（plugins/）

| 插件 | CMake option | 依赖组件 | 第三方库 |
|------|--------------|----------|----------|
| avox_onnx | `AVOX_ENABLE_ONNX` | — | ONNX Runtime |
| avox_opencv | `AVOX_ENABLE_OPENCV` | — | OpenCV |
| avox_cv | `AVOX_ENABLE_CV` | avox_onnx + avox_opencv | (onnx+opencv) |
| avox_sherpa | `AVOX_ENABLE_SHERPA` | — | sherpa-onnx + sentencepiece + onnxruntime |
| avox_translation | `AVOX_ENABLE_TRANSLATION` | — | onnxruntime |
| avox_webrtc | (见 plugins/CMakeLists) | — | WebRTC |
| avox_avatar | `AVOX_ENABLE_AVATAR` | avox_onnx (运行期) | onnxruntime |
| avox_ocr | `AVOX_ENABLE_OCR` | avox_onnx | onnxruntime |
| avox_openvino | `AVOX_ENABLE_OPENVINO` | — | OpenVINO Runtime |

**插件间依赖机制**（`register_plugin` 的 `DEPS` 参数）：
- `loadModule` 递归加载依赖 + 失败传播
- 例如 `avox_cv` 依赖 `avox_onnx` + `avox_opencv`，加载 avox_cv 时先加载其依赖

## 6. 构建依赖（构建脚本顺序）

[build_windows.py](../../build_windows.py) 按顺序构建第三方库，有改动才重新编译：

```bash
zlmediakit → fdk-aac → freetype → sherpa-onnx → sentencepiece → avplay (avox.dll)
```

| 库 | 关键 CMake 参数 |
|----|----------------|
| ZLMediaKit | `-DENABLE_TESTS=OFF -DENABLE_API=ON -DENABLE_WEBRTC=OFF -DENABLE_OPENSSL=ON` |
| sentencepiece | `-DSPM_ENABLE_MSVC_MT_BUILD=ON -DBUILD_SHARED_LIBS=OFF` |
| freetype | `-DDISABLE_FORCE_DEBUG_POSTFIX=ON` |
| sherpa-onnx | `-DSHERPA_ONNX_ENABLE_C_API=ON -DBUILD_SHARED_LIBS=ON` |

## 7. 关键约束

### 7.1 跨 DLL 安全
- 全链路 `/MT` 静态 CRT（Windows）
- 插件接口只传 `const char*` 与原生类型，STL 容器不跨 DLL 传递
- `IModule` 对象由插件 `new`，unload 时直接 `delete`（/MT 配置下跨 dll new/delete 安全）

### 7.2 特殊注意事项
- Android：静态库内部符号隐藏（`--exclude-libs,ALL`），防止 sentencepiece 和 sherpa-onnx 的 protobuf 版本冲突崩溃
- Agent 用 WebRTC 的 BoringSSL：只作用到 `AgentClient.cpp` / `HttplibTransport.cpp` 两个编译单元
- ZLMediaKit 在 iOS 用静态库，`ENABLE_OPENSSL` 可能与 webrtc 的 openssl 重复定义冲突
