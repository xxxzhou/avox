# 05 构建与运行

## 1. 构建环境要求

| 平台 | 依赖 |
|------|------|
| Windows | Visual Studio 2022 (x64/x86)、CMake ≥ 3.20、Python 3 |
| Android | Android SDK + NDK 26.1 (硬解需要)、Ninja、CMake |
| iOS | macOS + Xcode、CMake、Python 3 |
| Linux | CMake、Unix Makefiles、编译器 (clang++/g++) |
| WebAssembly | Emscripten (非 win32/linux 同层) |

## 2. 构建脚本（Python 封装）

项目提供统一的 Python 构建脚本，封装 CMake 调用。

### 2.1 [build_common.py](../../build_common.py) — 通用逻辑

主要配置：

```python
AVOX_BUILD_TYPE      # Debug/Release (环境变量 AVOX_BUILD_TYPE 覆盖)
AVOX_TARGET_SYSTEM   # windows/android/linux/ios
AVOX_TARGET_ARCH     # x64/arm64-v8a/arm64/x86_64
AVOX_FORCE_REBUILD   # 强制重新构建
AVOX_NDK_ROOT        # Android NDK 路径 (硬编需要 26)
AVOX_NINJA_PATH      # Ninja 路径 (Windows 编 Android)
```

### 2.2 [build_windows.py](../../build_windows.py) — Windows 构建

```bash
python build_windows.py
```

- 默认 `Release` 构建（可用 `AVOX_BUILD_TYPE=Debug` 覆盖）
- 环境变量 `AVOX_CMAKE_ARGS` 透传额外 cmake 参数（如 `-DAVOX_ENABLE_OPENVINO=ON -DAVOX_ENABLE_SWIG=OFF`）
- 按顺序构建第三方库：zlmediakit → fdk-aac → freetype → sherpa-onnx → sentencepiece → avox.dll
- 各库有改动才重新编译（`check_module` 检测产物是否存在）

### 2.3 Android 构建

修改 `build_common.py` 中 `AVOX_TARGET_SYSTEM = "android"` 后运行构建脚本，或直接：

```bash
python build_android.py    # 若存在
```

Android 需先下载 onnxruntime：
```bash
python script/onnx/down_onnxruntime_android.py
```

### 2.4 iOS 构建

- 需 macOS + Xcode
- 使用 `cmake/ios.toolchain.cmake`
- 默认架构 `arm64`（真机），部署目标 iOS 15.0
- 产物为 `avox.bundle`（含 glsl/images/fonts/config/agent/script/models 资源）
- 集成方式：`avox.podspec`（CocoaPods）

## 3. CMake 直接构建

### 3.1 核心选项

| 选项 | 默认 | 说明 |
|------|------|------|
| `AVOX_ENABLE_FFMPEG` | ON | FFmpeg 软/硬解 |
| `AVOX_ENABLE_VULKAN` | ON | Vulkan GPU 图像处理 |
| `AVOX_ENABLE_VULKAN_DECODE` | OFF | Vulkan 视频解码 |
| `AVOX_ENABLE_ZLMEDIAKIT` | ON | ZLMediaKit 直播流 |
| `AVOX_ENABLE_FREETYPE` | ON | FreeType 文字渲染 |
| `AVOX_ENABLE_AGENT` | ON | Agent 客户端 |
| `AVOX_ENABLE_CLI` | ON | avox_cli 命令行工具 |
| `AVOX_ENABLE_PLUGINS` | ON | 插件总开关 |
| `AVOX_ENABLE_OPENCV` | ON | OpenCV 插件 |
| `AVOX_ENABLE_SHERPA` | ON | sherpa-onnx 插件 |
| `AVOX_ENABLE_ONNX` | ON | ONNX 插件 |
| `AVOX_ENABLE_TRANSLATION` | ON | 翻译插件 |
| `AVOX_ENABLE_CV` | ON | 水印去除/YOLO 插件 |
| `AVOX_ENABLE_OCR` | ON | OCR 插件 |
| `AVOX_ENABLE_AVATAR` | ON | 虚拟人插件 |
| `AVOX_ENABLE_OPENVINO` | OFF | OpenVINO 插件 |
| `AVOX_ENABLE_SWIG` | OFF | SWIG 多语言绑定 |
| `AVOX_DLL_TYPE` | — | SHARED/STATIC |

### 3.2 Windows 直接构建示例

```bash
cmake -B build/windows -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Release
cmake --build build/windows --config Release --parallel
```

### 3.3 输出目录

- `avox.dll` 输出到 `build/{platform}/avox/install/AMD64/{config}/`（Windows）
- 插件 `avox_<name>.dll` 输出到 avox.dll 同级的 `plugins/` 子目录
- 资源 (glsl/images/fonts/config/agent/script/models) 通过 `avox_copy_assets` 复制到安装目录

## 4. 产物说明

| 产物 | 说明 |
|------|------|
| `avox.dll` / `libavox.so` / `libavox.a` | 核心 SDK 库 |
| `avox_<name>.dll` / `libavox_<name>.so` | 动态插件 |
| `avox_cli` / `avox_cli.exe` | 命令行工具 |
| `avox.bundle` | iOS 资源包 |
| SWIG 绑定 | C#/Java/Node.js/Python 语言封装 |

## 5. 运行方式

### 5.1 运行目录结构

运行期要求 avox.dll 同级目录有：

```
<运行目录>/
├── avox.dll
├── plugins/           # 动态插件 (懒加载扫描)
├── glsl/              # GLSL/SPIR-V 着色器
├── images/            # 图像资源
├── fonts/             # 字体
├── config/            # 配置 (agent.json/cli.json)
├── agent/             # Agent 技能
├── script/            # 脚本资源
└── models/            # AI 模型 (stt/tts/translation/quality/inpaint/avatar)
```

### 5.2 avox_cli 命令行工具（[src/avox_cmd/README.md](../../src/avox_cmd/README.md)）

```bash
avox_cli <子命令> [全局选项] [子命令选项]
```

**子命令一览：**

| 子命令 | 功能 |
|--------|------|
| `device` | 枚举设备 |
| `play` | 播放音视频 |
| `record` | 录制/转存流 |
| `transcode` | 转码录制 |
| `inpaint` | AI 去水印 |
| `translate` | 翻译文本 |
| `asr` | 语音识别 |
| `webrtc` | WebRTC 推拉流 |
| `image` | 图片处理 |
| `agent` | AI 对话 |
| `vulkan` | Vulkan 信息 |

**全局选项：** `-loglevel` / `-version` / `-help` / `-json`

**使用示例（见 [assets/config/cli.json](../../assets/config/cli.json)）：**
```bash
avox_cli play -io auto -i <url>              # 播放
avox_cli record -io ffmpeg -i <url>          # 录制 (转封装)
avox_cli record -io ffmpeg -tc -i <url>      # 录制 (转码)
avox_cli vision -s D://1.jpg                 # OCR 识别图片
```

### 5.3 日志

- 通过 `setLogAction` / `setLogObserver` 设置日志回调
- 模块内使用 `module/LogHelper.hpp` 的辅助输出
- CLI 可用 `-loglevel` 控制级别

## 6. CI/CD（[.github/workflows/release.yml](../../.github/workflows/release.yml)）

Release 工作流（Windows + Android）：
1. 缓存 Git 子模块（`3rdparty/`）
2. 从 `avc_library` 仓库拉取预编译库（webrtc/onnxruntime，需 `AVOX_LIBRARY_TOKEN`）
3. 缓存并下载 AI 模型（从 `avox_model` Release）
4. 构建并发布到 GitHub Release

## 7. 测试

- `tests/` — 单元测试（doctest，随主构建自动编译，`AVOX_BUILD_TESTS=ON` 默认开启）
  ```bash
  ctest --test-dir build/windows/avox --output-on-failure -C Release
  ```
  覆盖：AvoxMath 向量/矩阵、H26XHelper annexb/avcc 检测与 extradata 组包拆包往返
- `samples/` — 各功能测试示例（播放/录制/AI 等）
- `platform/` — 平台集成演示（Avalonia/Android/Godot/WASM）

## 8. 发布

- Windows：CPack 打包（`cmake/avox_cpack.cmake`）
- iOS：CocoaPods（`avox.podspec`）
- Android：`jniLibs` 集成
- WebAssembly：Emscripten 编译，AVOX_EXPORT 用 `EMSCRIPTEN_KEEPALIVE`
