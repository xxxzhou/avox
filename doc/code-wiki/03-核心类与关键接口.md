# 03 核心类与关键接口

> 本文档介绍核心类、关键接口与模块注册机制。所有公共接口均在 `src/avox/` 下的 `.h` 文件中，
> 供外部调用与 SWIG 绑定使用。

## 1. 基础概念

- **命名空间**：`avox`（`namespace avox {` / `}`）
- **导出宏**：`AVOX_EXPORT`（见 [AvoxDef.h](../../src/avox/AvoxDef.h)），插件用 `AVOX_PLUGIN_API`
- **资源生命周期约定**：
  - `create*()` 返回的对象需调用方释放（`delete`）
  - `get*()` 返回托管对象（不要释放）
  - `addXxxOb/removeXxxOb` 注册/注销观察者

### 2.2 `ModuleMgr`（[module/ModuleMgr.hpp](../../src/avox/module/ModuleMgr.hpp)）

插件管理器，单例（`ModuleMgr::Get()`）。职责：
- 扫描 `plugins/` 目录，动态加载 `avox_*` 插件（`scanPluginsDir` / `startup` / `ensureStarted`）
- 注册/加载/卸载模块（`registerModule` / `loadModule` / `unloadModule` / `regAndLoad`）
- 检查模型是否已加载（`checkLoadModel`）

`ensureStarted()` 幂等懒加载：首次调用触发 `startup()`（扫描 plugins/ + 加载），核心模块（如 SubtitleAsr）构造时调用一次，确保依赖的插件工厂已注册。

### 2.3 `IModule`（[module/IModule.hpp](../../src/avox/module/IModule.hpp)）

插件基类。所有插件实现 `IModule` 子类：

```cpp
class IModule {
  virtual bool loadModule(IOption* option);   // 运行期能力探测 + 初始化 (false=不可用)
  virtual void unloadModule();                 // 卸载
  void addDep(const char* name);               // 添加依赖
};
```

**插件注册宏：**
- 动态模式：`AVOX_REGISTER_MODULE(ModuleClass, name)` 导出 `NewModule()` + `GetModuleABI()`
- 静态模式（iOS/WASM）：实例化 `StaticLinkModule<ModuleClass>` 构造期注册

### 2.4 注册模板（[module/RegeditObj.hpp](../../src/avox/module/RegeditObj.hpp)）

| 模板 | 语义 |
|------|------|
| `RegeditObj<OBJTYPE, OBJCLASS, DESC>` | 一个类型对应一个实现 |
| `RegeditObjList<OBJTYPE, OBJCLASS, DESC>` | 一个类型对应多个实现 |
| `RegeditFactory<OBJCLASS>` | 插件工厂（string key + C 函数指针，跨 DLL 安全） |
| `RegeditMgr<OBJTYPE, OBJCLASS>` | 单例管理器（延迟初始化） |
| `RegeditSingleton<OBJCLASS>` | 全局单例（不 delete 实例） |

## 3. 播放器接口（[AvoxPlayer.h](../../src/avox/AvoxPlayer.h)）

### 3.1 `IMediaPlayer` — 媒体播放器

| 方法 | 说明 |
|------|------|
| `getOption()` | 返回内置参数设置器 |
| `setIoPlan(IoPlan)` | 设置 IO 方案（ffmpeg/zlmediakit） |
| `setHardDecode(bool)` | 设置是否硬解 |

| `getRate(TrackType, bool bAvg)` / `getLossRate()` / `getFps()` | 码率/丢包率/帧率 |

### 3.2 `ISourcePlayer` — 原始数据播放器

针对外挂 IRawSource 的简单播放器（无队列同步，PCM/YUV/GPUTexture 直出）：

```cpp
class ISourcePlayer {
  ISurfaceRender* getSurfaceRender();
  IAudioRender* getAudioRender();
  void setAudioSource(IAudioSource* source);   // 设置音频设备
  void setVideoSource(IVideoSource* source);   // 设置视频设备
  IMediaMuxer* getMuxer();
  bool open() / close();
};
```

### 3.3 `IRtcPlayer` — WebRTC 推拉流播放器

```cpp
class IRtcPlayer {
  void setRollType(RtcRollType type);         // offer/answer

  ISourceInfo* getRemoteSourceInfo() / getLocalSourceInfo();
  ISurfaceRender* getRemoteSurfaceRender() / getLocalSurfaceRender();
  const char* getLocalSdp() / setRemoteSdp();

```
