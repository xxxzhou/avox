# 02 目录结构与模块职责

## 1. 顶层目录结构

```
avplay/
├── CMakeLists.txt          # 根 CMake 构建文件
├── build_common.py         # 通用构建脚本 (CMake 封装)
├── build_windows.py        # Windows 构建脚本
├── build_android.py        # Android 构建脚本
├── .gitmodules             # Git 子模块定义
├── .github/workflows/      # CI/CD 工作流 (release.yml)
├── src/                    # 核心源码 (avox.dll 主要构建)
├── plugins/                # 动态插件模块 (独立 dll/so)
├── 3rdparty/               # Git 子模块第三方库
├── avc_library/            # 大型预编译库 (onxxruntime, webrtc, openssl 等)
├── assets/                 # 运行期资源 (glsl/模型/字体/配置/脚本/图片)
├── cmake/                  # CMake 辅助模块
├── doc/                    # 设计文档
├── swig/                   # SWIG 多语言绑定
├── samples/                # 示例代码
├── platform/               # 平台集成演示 (Avalonia/Android/Godot/WASM)
├── glsl/                   # GLSL 着色器源码 (编译为 SPIR-V)
├── script/                 # 辅助脚本 (模型下载等)
├── avox.podspec             # iOS CocoaPods 配置
├── CLAUDE.md               # 项目总览 (AI 辅助用)
├── DeveloperGuide.md       # 开发规范
└── README.md               # 项目 README
```

## 2. 核心模块 (src/)

### 2.1 `src/avox/` — 播放器核心框架

| 子目录 | 职责 |
|--------|------|
| `avox/` | 公共头文件 (AvoxXXX.h) + SDK 初始化 (Avox.cpp) |
| `avox/player/` | IMediaPlayer / ISourcePlayer 实现 + 播放器状态机 + 音视频同步 |
| `avox/source/` | 数据源 (AVSource 编码数据 / RawSource 原始数据 / DeviceManager 设备管理) |
| `avox/audio/` | 音频解码/编码/渲染/STT/TTS/Process/Face 抽象基类 |
| `avox/video/` | 视频解码/编码/渲染/图像处理抽象基类 + Window 管理 |
| `avox/codec/` | 编解码器辅助工具 |
| `avox/muxer/` | 媒体复用 (IOMuxer) 抽象 |
| `avox/layer/` | 渲染层管理 (VkInputLayer/VkOutputLayer 等) |
| `avox/subtitle/` | 字幕 (SRT/ASR/翻译) |
| `avox/module/` | 模块注册 (AvoxManager/ModuleMgr/RegeditObj/IModule) |
| `avox/vision/` | 视觉处理抽象 (IONNXSession/IOVEngine/OnnxSessionCache) |
| `avox/avatar/` | 虚拟人抽象 (VideoFace/BodyFace) |
| `avox/Input/` | 输入注入 (鼠标/键盘) 抽象 |

**关键文件：**
- `AvoxDef.h` — 基础宏 (命名空间/导出/C++17/OpenCV 兼容类型)
- `AvoxCore.h` — 聚合头 (包含所有 AvoxXXX.h)
- `Avox.cpp` — SDK 初始化、日志、工具函数实现
- `AvoxPlayer.h` — IMediaPlayer / ISourcePlayer / IRtcPlayer 接口
- `AvoxSource.h` — IAVSource / IRawSource / 设备管理接口
- `AvoxMuxer.h` — IMediaMuxer / IRecorder 接口
- `AvoxBase.h` — IOption / ITranslator / IPyRunner 基础接口
- `AvoxVision.h` — 视觉接口 (ITemplateMatcher/ITextRecognizer/IYoloDetector 等)
- `AvoxAvatar.h` — IVideoFace / IBodyFace 虚拟人接口
- `AvoxInput.h` — IInputController / IScreenCapture 接口
- `AvoxCodec.h` — 编解码器枚举与描述
- `AvoxAudio.h` — 音频格式/渲染/STT/TTS/Avatar 接口
- `AvoxVideo.h` — YUV 格式/视频描述/帧操作
- `AvoxImage.h` — IImageBuffer 图像缓冲接口
- `AvoxLayer.h` — 渲染管线图 (IPipeGraph/INode/ISurfaceRender)
- `AvoxLog.h` — 日志接口
- `AvoxBuffer.h` — 数据缓冲
- `AvoxMath.h` — 数学工具
- `AvoxTime.h` — 时间工具
- `AvoxVersion.h` — 版本号

### 2.2 `src/avox_ffmpeg/` — FFmpeg 集成

| 子目录 | 职责 |
|--------|------|
| `avox_ffmpeg/` | FFmpeg 解封装 + 协议解析 |
| `avox_ffmpeg/decoder/` | FFmpeg 软解 + 硬解 (DX11/MediaCodec/VideoToolbox) |
| `avox_ffmpeg/encoder/` | FFmpeg 编码器 |

由 `AVOX_ENABLE_FFMPEG` 开关控制。

### 2.3 `src/avox_zlmediakit/` — ZLMediaKit 集成

直播流解析 (RTSP/RTMP/ONVIF) + SDP 信令交换 (TestSdpOb)。

由 `AVOX_ENABLE_ZLMEDIAKIT` 开关控制。

### 2.4 `src/avox_vulkan/` — Vulkan GPU 图像处理管线

| 子目录 | 职责 |
|--------|------|
| `avox_vulkan/` | Vulkan 核心封装 |
| `avox_vulkan/layer/` | 处理层 (VkInputLayer/VkOutputLayer/VkFilterLayer 等) |
| `avox_vulkan/vulkan/` | Vulkan 渲染 (VkVideoRender) |
| `avox_vulkan/share/` | 跨设备共享 |
| `avox_vulkan/extra/` | 额外效果 |
| `avox_vulkan/geometry/` | 几何处理 |
| `avox_vulkan/quality/` | 画质增强 (Real-ESRGAN/FSR/Anime4K) |
| `avox_vulkan/decode/` | Vulkan 视频解码 (AVOX_ENABLE_VULKAN_DECODE) |
| `avox_vulkan/windows/` | Windows 平台 (DX11/DX12 互操作) |
| `avox_vulkan/android/` | Android 平台 (OpenGLES 互操作) |
| `avox_vulkan/ios/` | iOS 平台 (Metal 互操作) |

由 `AVOX_ENABLE_VULKAN` 开关控制。

### 2.5 `src/avox_freetype/` — FreeType 文字渲染

由 `AVOX_ENABLE_FREETYPE` 开关控制。提供 IFontLayer 文字渲染层。

### 2.6 `src/avox_aac/` — AAC 编解码

整合 faad2 (解码) / faac (编码) / fdk-aac (编解码)。
由 `AVOX_ENABLE_FAAD2` / `AVOX_ENABLE_FAAC` / `AVOX_ENABLE_FDKAAC` 开关控制。

### 2.7 `src/avox_agent/` — AI Agent 客户端

| 子目录 | 职责 |
|--------|------|
| `avox_agent/` | Agent 核心 (AgentClient/AgentSession) |
| `avox_agent/core/` | 会话事件日志 + 持久化 |
| `avox_agent/policy/` | 策略 (超时/循环卫生/溢出/审批/压缩/模型路由) |
| `avox_agent/compose/` | 装配 (AgentHost/AgentConfig/DiagnosticAgent) |
| `avox_agent/adapter/` | 适配器 (对接旧 provider/transport) |
| `avox_agent/skills/` | Agent 技能 |
| `avox_agent/tools/` | Agent 工具 |
| `avox_agent/transport/` | 传输层 (HttplibTransport/SSE) |
| `avox_agent/provider/` | LLM 提供者 (OpenAI 兼容 API) |
| `avox_agent/cli/` | Agent CLI 入口 (AVOX_ENABLE_AGENT + AVOX_ENABLE_CLI) |

由 `AVOX_ENABLE_AGENT` 开关控制。

### 2.8 `src/avox_cmd/` — CLI 命令框架

| 子目录 | 职责 |
|--------|------|
| `avox_cmd/` | 参数解析 (ArgParser) + 命令注册 (CmdRegistry) |
| `avox_cmd/commands/` | 各子命令实现 (CmdPlay/CmdDevice 等) |
| `avox_cmd/cli/` | avox_cli 薄壳 (main.cpp + CMakeLists.txt) |
| `avox_cmd/doc/` | 设计文档 |

命令逻辑折进 `avox.dll`，cli 薄壳仅在 `AVOX_ENABLE_CLI` 时编译独立 exe。

### 2.9 平台模块

| 模块 | 目录 | 职责 |
|------|------|------|
| avox_windows | `src/avox_windows/` | Windows 平台 (DX11/DX12/WinRT/音频设备) |
| avox_android | `src/avox_android/` | Android 平台 (MediaCodec 硬解/设备管理) |
| avox_ios | `src/avox_ios/` | iOS 平台 (VideoToolbox 硬解) |
| avox_linux | `src/avox_linux/` | Linux 平台 |
| avox_egl | `src/avox_egl/` | EGL 上下文 (Android 等平台) |

## 3. 插件模块 (plugins/)

所有插件编译为独立 `avox_<name>.dll` / `libavox_<name>.so`，运行期由 ModuleMgr 扫描并懒加载。

| 插件 | 目录 | 职责 | 依赖 |
|------|------|------|------|
| avox_onnx | `plugins/avox_onnx/` | ONNX Runtime 推理引擎 | ONNX Runtime 库 |
| avox_opencv | `plugins/avox_opencv/` | OpenCV 图像处理 (模板匹配/特征匹配/颜色检测/方向检测/地图定位/掩码生成) | OpenCV 库 |
| avox_cv | `plugins/avox_cv/` | AI 图像修复 (水印去除) + 通用 YOLO 检测 | avox_onnx + avox_opencv |
| avox_sherpa | `plugins/avox_sherpa/` | Sherpa-ONNX 语音识别 (ASR) + 语音合成 (TTS) | sherpa-onnx + onnxruntime |
| avox_translation | `plugins/avox_translation/` | 离线神经机器翻译 | onnxruntime |
| avox_webrtc | `plugins/avox_webrtc/` | WebRTC 推拉流 | WebRTC 库 |
| avox_avatar | `plugins/avox_avatar/` | 虚拟人 (音频→blendshape / 视频→blendshape+landmark / 身体姿态) | avox_onnx |
| avox_ocr | `plugins/avox_ocr/` | OCR 文字识别 (PP-OCRv6) | avox_onnx |
| avox_openvino | `plugins/avox_openvino/` | OpenVINO 推理 (Intel iGPU/CPU) | OpenVINO 库 |

详细设计见 `plugins/README.md`。
