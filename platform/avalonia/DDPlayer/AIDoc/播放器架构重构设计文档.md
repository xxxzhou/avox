# 播放器架构重构设计文档（最终版）

## 概述

本文档描述了 Avalonia 平台播放器架构的重构，将原有的 `AvPlayer` 中心化设计改为基于具体接口的分层架构，使每个播放器类型（IMediaPlayer、ISourcePlayer、IRtcPlayer）都有独立的封装。

## 现有问题

原来的设计以 `AvPlayer` 为主，通过 `AvPlayerModel` 控制 `AvPlayer`，`AvRenderView` 也基于 `AvPlayerModel` 设计。但实际上 `IMediaPlayer`、`ISourcePlayer`、`IRtcPlayer` 接口差异很大，只有 `IMediaPlayerOb` 回调是共同的。

## 新架构设计

### 核心原则

1. **共同基类**: `BasePlayer` 实现 `IMediaPlayerOb` 回调接口，这是三个播放器的共同基类
2. **独立封装**: 每个播放器接口都有独立的封装类，各司其职
3. **分层 Model**: 每个 Model 类独立，不依赖 PlayerModel 基类
4. **功能分离**: 
   - 截图功能在 `RenderView` 上（因为截图应该在 ISurfaceRender 上）
   - 音量控制在 `AudioModel` 上（因为音量应该在 IAudioRender 上）
5. **渲染解耦**: `RenderView` 以 `ISurfaceRender` 为主体，不依赖特定 Model

## 类结构说明

### 1. BasePlayer (基类)

**位置**: `AvoxControls/BasePlayer.cs`

**职责**:
- 实现 `IMediaPlayerOb` 回调接口（三个播放器共用的回调）
- 提供通用状态管理（CurrentState、IsPlaying、IsPaused、IsStopped）
- 提供通用事件通知（OnStateChanged、OnIoError、OnDecodeError 等）
- 实现日志记录

**关键属性**:
- `CurrentState`: 当前播放状态
- `IsPlaying`: 是否正在播放
- `IsPaused`: 是否已暂停
- `IsStopped`: 是否已停止

**关键事件**:
- `OnStateChanged`: 状态变更事件
- `OnIoError`: IO 错误事件
- `OnDecodeError`: 解码错误事件
- `OnReady`: 就绪事件
- `OnComplete`: 完成事件
- `OnSeek`: Seek 事件
- `OnPause`: 暂停事件
- `OnResume`: 恢复事件
- `OnClose`: 关闭事件

### 2. MediaPlayer (IMediaPlayer 封装)

**位置**: `AvoxControls/MediaPlayer.cs`

**职责**:
- 封装 `AvoxNet.IMediaPlayer` 接口
- 提供媒体文件/直播流的播放功能
- 支持 Seek、暂停、恢复、变速等操作
- 支持硬解/软解切换

**关键方法**:
- `Open(string url)`: 打开媒体文件或流
- `Close()`: 关闭媒体
- `Seek(long pos)`: Seek 到指定位置
- `Pause()`: 暂停播放
- `Resume()`: 恢复播放
- `SetSpeed(double speed)`: 设置播放速度
- `GetSurfaceRender()`: 获取视频渲染器
- `GetAudioRender()`: 获取音频渲染器
- `GetMuxer()`: 获取复用器
- `SetIoPlan(IoPlan plan)`: 设置 IO 计划（ffmpeg/zlmediakit）
- `SetHardDecode(bool hard)`: 设置是否使用硬件解码

**适用场景**:
- 播放本地视频文件
- 播放网络直播流
- 需要 Seek 操作的媒体
- 需要音视频同步的场景

### 3. SourcePlayer (ISourcePlayer 封装)

**位置**: `AvoxControls/SourcePlayer.cs`

**职责**:
- 封装 `AvoxNet.ISourcePlayer` 接口
- 提供直出设备源的播放功能
- 不需要解码器，也不需要音视频同步
- 支持设置音视频源

**关键方法**:
- `Open()`: 打开源播放
- `Close()`: 关闭源播放
- `SetVideoSource(IVideoSource source)`: 设置视频源
- `SetAudioSource(IAudioSource source)`: 设置音频源
- `GetSurfaceRender()`: 获取视频渲染器
- `GetAudioRender()`: 获取音频渲染器
- `GetMuxer()`: 获取复用器

**适用场景**:
- 摄像头预览
- 屏幕录制实时显示
- 麦克风音频实时播放
- 不需要 Seek 的实时源

### 4. RtcPlayer (IRtcPlayer 封装)

**位置**: `AvoxControls/RtcPlayer.cs`

**职责**:
- 封装 `AvoxNet.IRtcPlayer` 接口
- 提供 WebRTC 协议的推拉流功能
- 支持设置 SDP 和 ICE 候选
- 支持本地和远端渲染

**关键方法**:
- `Open()`: 打开 RTC 连接
- `Close()`: 关闭 RTC 连接
- `SetRollType(RtcRollType type)`: 设置角色类型（Offer/Answer）
- `SetVideoSource(IVideoSource videoSource)`: 设置视频源
- `SetAudioSource(IAudioSource audioSource)`: 设置音频源
- `GetLocalSurfaceRender()`: 获取本地渲染器（预览）
- `GetRemoteSurfaceRender()`: 获取远端渲染器（拉流）
- `GetAudioRender()`: 获取音频渲染器
- `GetLocalSdp()`: 获取本地 SDP
- `SetRemoteSdp(string sdp)`: 设置远端 SDP
- `AddIceCandidate(...)`: 添加 ICE 候选

**适用场景**:
- WebRTC 视频通话
- 实时音视频推流
- P2P 数据传输
- 需要 WebRTC 低延迟特性的场景

### 5. RenderView (渲染视图)

**位置**: `AvoxControls/RenderView.cs`

**职责**:
- 以 `ISurfaceRender` 为主体封装
- 提供跨平台原生窗口渲染支持
- 支持 Vulkan/DX11/DX12/Metal/OpenGL ES 等多种渲染后端
- 平台适配（Windows/Android/iOS/Linux）
- **提供截图功能**

**关键属性**:
- `WindowRender`: 窗口渲染器接口
- `UseVulkanRendering`: 是否使用 Vulkan 渲染

**关键命令和事件**:
- `TakeScreenshotCommand`: 截图命令
- `OnTakeScreenshotRequested`: 截图请求事件

**平台支持**:
- **Windows**: 直接使用原生窗口句柄
- **Android**: 使用 SurfaceView 和 ANativeWindow
- **iOS**: 使用 UIView 和 CAMetalLayer
- **Linux**: 使用原生窗口句柄

**特点**:
- 不依赖特定的播放器 Model
- 可以绑定任何播放器的 ISurfaceRender
- 自动处理平台差异
- 支持 GPU 渲染和 CPU 渲染
- 截图功能通过 `OnTakeScreenshotRequested` 事件通知上层

### 6. AudioModel (音频渲染 Model)

**位置**: `AvoxControls/AudioModel.cs`

**职责**:
- 封装 `IAudioRender` 接口
- 提供音量控制、静音等功能
- 提供音频渲染相关的 UI 数据绑定支持

**关键属性**:
- `AudioRender`: 音频渲染器接口
- `IsMuted`: 是否静音
- `Volume`: 音量（0.0 - 1.0）

**关键命令**:
- `ToggleMuteCommand`: 切换静音命令
- `SetVolumeCommand`: 设置音量命令

**特点**:
- 独立管理音频渲染，不依赖播放器
- 可以单独使用，也可以与播放器配合使用
- 音量设置自动应用到绑定的 IAudioRender
- 静音功能通过设置音量为 0 实现

### 7. MediaModel (MediaPlayer Model)

**位置**: `AvoxControls/MediaModel.cs`

**职责**:
- 封装 `MediaPlayer` 的所有功能
- 提供 UI 数据绑定支持（实现 INotifyPropertyChanged）
- 提供 Seek、暂停、恢复、变速等操作的命令
- 提供播放位置、时长、进度等信息

**关键属性**:
- `Player`: MediaPlayer 实例
- `CurrentState`: 当前播放状态
- `Position`: 当前播放位置（毫秒）
- `Duration`: 媒体总时长（毫秒）
- `PlaybackSpeed`: 当前播放速度
- `Process`: 播放进度（0-1）
- `Fps`: 帧率
- `VideoRate`: 视频码率
- `AudioRate`: 音频码率
- `SourceInfo`: 源信息

**关键方法**:
- `Open(string url, IoPlan ioPlan, bool hardDecode)`: 打开媒体
- `Play()`: 播放
- `Pause()`: 暂停
- `Close()`: 关闭
- `Seek(long pos)`: Seek
- `SetSpeed(double speed)`: 设置播放速度
- `UpdatePosition()`: 更新播放位置

**关键命令**:
- `PlayCommand`: 播放命令
- `PauseCommand`: 暂停命令
- `CloseCommand`: 关闭命令
- `SetSpeedCommand`: 设置速度命令

### 8. SourceModel (SourcePlayer Model)

**位置**: `AvoxControls/SourceModel.cs`

**职责**:
- 封装 `SourcePlayer` 的所有功能
- 提供 UI 数据绑定支持
- 提供音视频源设置功能
- 提供打开/关闭操作

**关键属性**:
- `Player`: SourcePlayer 实例
- `CurrentState`: 当前播放状态

**关键方法**:
- `Open()`: 打开源播放

- `SetVideoSource(IVideoSource source)`: 设置视频源
- `SetAudioSource(IAudioSource source)`: 设置音频源
- `GetSurfaceRender()`: 获取视频渲染器
- `GetAudioRender()`: 获取音频渲染器
- `GetMuxer()`: 获取复用器

**关键命令**:

## 使用示例

### 1. 播放本地视频文件

```csharp
// 创建 MediaModel
var mediaModel = new MediaModel();

// 创建 RenderView（视频渲染）
var renderView = new RenderView();
renderView.UseVulkanRendering = true;

// 创建 AudioModel（音频控制）
var audioModel = new AudioModel();

// 打开视频文件
mediaModel.Open("D:/Videos/test.mp4", IoPlan.ffmpeg, true);

// 绑定渲染器
renderView.WindowRender = mediaModel.GetSurfaceRender();

// 绑定音频渲染器
audioModel.AudioRender = mediaModel.GetAudioRender();

// 订阅截图事件
renderView.OnTakeScreenshotRequested += (sender, e) =>
{
    AvoxWrapper.logMsg(LogLevel.info, "截图触发");
    // 执行截图逻辑
};

// 播放
mediaModel.Play();

// 获取状态
AvoxWrapper.logMsg(LogLevel.info, $"播放状态: {mediaModel.CurrentState}");
AvoxWrapper.logMsg(LogLevel.info, $"播放进度: {mediaModel.Process:P2}");
AvoxWrapper.logMsg(LogLevel.info, $"帧率: {mediaModel.Fps}");

// Seek 到 10 秒位置
mediaModel.Seek(10000);

// 设置播放速度为 1.5 倍
mediaModel.SetSpeed(1.5);

// 调整音量（通过 AudioModel）
audioModel.Volume = 0.5;
audioModel.IsMuted = false;

// 暂停
mediaModel.Pause();

// 恢复
mediaModel.Play();

// 关闭
mediaModel.Close();
```

### 2. 摄像头预览

```csharp
// 创建 SourceModel
var sourceModel = new SourceModel();

// 创建 RenderView
var renderView = new RenderView();
renderView.UseVulkanRendering = true;

// 创建 AudioModel
var audioModel = new AudioModel();

// 绑定渲染器
renderView.WindowRender = sourceModel.GetSurfaceRender();

// 绑定音频渲染器
audioModel.AudioRender = sourceModel.GetAudioRender();

// 创建摄像头源
var cameraSource = VideoManager.Get().createVideoSource(DeviceType.camera);
sourceModel.SetVideoSource(cameraSource);

// 打开预览
sourceModel.Open();

// 获取源信息
AvoxWrapper.logMsg(LogLevel.info, $"源信息: {sourceModel.SourceInfo}");

// 可以同时录制
var muxer = sourceModel.GetMuxer();
muxer.open("D:/output.mp4", MuxerType.file);

// 调整音量
audioModel.Volume = 0.8;

// 关闭预览
sourceModel.Close();
```

### 3. WebRTC 视频通话

```csharp
// 创建 RtcModel
var rtcModel = new RtcModel();

// 创建本地预览 RenderView
var localRenderView = new RenderView();
localRenderView.UseVulkanRendering = true;

// 创建远端显示 RenderView
var remoteRenderView = new RenderView();
remoteRenderView.UseVulkanRendering = true;

// 创建 AudioModel
var audioModel = new AudioModel();

// 绑定渲染器
localRenderView.WindowRender = rtcModel.GetLocalSurfaceRender();
remoteRenderView.WindowRender = rtcModel.GetRemoteSurfaceRender();

// 绑定音频渲染器
audioModel.AudioRender = rtcModel.GetAudioRender();

// 订阅截图事件
localRenderView.OnTakeScreenshotRequested += (sender, e) =>
{
    AvoxWrapper.logMsg(LogLevel.info, "本地截图触发");
};

remoteRenderView.OnTakeScreenshotRequested += (sender, e) =>
{
    AvoxWrapper.logMsg(LogLevel.info, "远端截图触发");
};

// 设置角色类型
rtcModel.RollType = RtcRollType.offer;

// 创建音视频源
var cameraSource = VideoManager.Get().createVideoSource(DeviceType.camera);
var micSource = AudioManager.Get().createAudioSource(DeviceType.mic);
rtcModel.SetVideoSource(cameraSource);
rtcModel.SetAudioSource(micSource);

// 打开 RTC 连接
rtcModel.Open();

// 订阅 SDP 和 ICE 事件
rtcModel.OnLocalSdp += (sdp) =>
{
    AvoxWrapper.logMsg(LogLevel.info, $"本地 SDP: {sdp.Length} bytes");
    // 发送 SDP 到服务器或远端
};

rtcModel.OnIceCandidate += (candidate, mid, index) =>
{
    AvoxWrapper.logMsg(LogLevel.info, $"ICE 候选: mid={mid}, index={index}");
    // 发送 ICE 候选到服务器或远端
};

// 设置远端 SDP
rtcModel.SetRemoteSdp("远端返回的 SDP");

// 添加 ICE 候选
rtcModel.AddIceCandidate("ICE 候选字符串", "0", 0);

// 调整音量
audioModel.Volume = 0.9;

// 关闭连接
rtcModel.Close();
```

### 4. 在 Avalonia XAML 中使用

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:controls="using:AvoxControls"
             x:Class="AvoxControls.AvPlayerView">
    <StackPanel>
        <!-- 播放控制按钮 -->
        <StackPanel Orientation="Horizontal" Margin="10">
            <Button Content="Play" Command="{Binding PlayCommand}"/>
            <Button Content="Pause" Command="{Binding PauseCommand}"/>
            <Button Content="Close" Command="{Binding CloseCommand}"/>
        </StackPanel>

        <!-- 进度条 -->
        <ProgressBar Value="{Binding Process}" Maximum="1" Margin="10"/>

        <!-- 位置和时长 -->
        <TextBlock Margin="10">
            <Run Text="{Binding Position, StringFormat={}{0:0}"/>
            <Run Text="/"/>
            <Run Text="{Binding Duration, StringFormat={}{0:0}}"/>
        </TextBlock>

        <!-- 速度控制 -->
        <Slider Minimum="0.5" Maximum="2.0" Value="{Binding PlaybackSpeed}"
                TickFrequency="0.1" IsSnapToTickEnabled="True" Margin="10"/>

        <!-- 音量控制 -->
        <StackPanel Orientation="Horizontal" Margin="10">
            <Button Content="Mute" Command="{Binding AudioModel.ToggleMuteCommand}"/>
            <Slider Minimum="0" Maximum="1" Value="{Binding AudioModel.Volume}" Width="200"/>
        </StackPanel>

        <!-- 渲染视图 -->
        <controls:RenderView x:Name="RenderView" Height="480" UseVulkanRendering="True"/>
        
        <!-- 截图按钮 -->
        <Button Content="Screenshot" Command="{Binding RenderView.TakeScreenshotCommand}" Margin="10"/>
    </StackPanel>
</UserControl>
```

### 5. 后台代码绑定

```csharp
public partial class AvPlayerView : UserControl
{
    private MediaModel mediaModel = new MediaModel();
    private AudioModel audioModel = new AudioModel();
    
    public AvPlayerView()
    {
        InitializeComponent();
        
        DataContext = this;
        
        // 绑定渲染器
        RenderView.WindowRender = mediaModel.GetSurfaceRender();
        
        // 绑定音频渲染器
        audioModel.AudioRender = mediaModel.GetAudioRender();
    }
    
    public MediaModel MediaModel => mediaModel;
    public AudioModel AudioModel => audioModel;
}
```

## 优势总结

1. **职责清晰**: 每个类都有明确的职责，易于理解和维护
2. **功能分离**: 
   - 截图功能独立在 RenderView
   - 音量控制独立在 AudioModel
   - 播放器控制独立在各自的 Model
3. **类型安全**: 编译时就能发现接口不匹配的问题
4. **易于扩展**: 新增播放器类型只需实现相应的封装类
5. **解耦设计**: RenderView 不依赖特定播放器 Model，提高了复用性
6. **独立使用**: AudioModel 可以独立于播放器使用，提供更好的灵活性
7. **代码复用**: BasePlayer 提供了通用回调功能，减少重复代码
8. **平台无关**: 接口层独立于具体平台实现，便于跨平台移植

## 注意事项

1. **线程安全**: 播放器操作应尽量在主线程或 UI 线程进行
2. **资源释放**: 使用完毕后必须调用 Dispose() 释放资源
3. **错误处理**: 所有播放器操作都有异常处理，应订阅相应错误事件
4. **平台差异**: Android 和 iOS 平台不支持某些对话框功能，使用时需注意
5. **渲染绑定**: RenderView 必须在平台句柄准备好后才能绑定渲染器
6. **日志记录**: 所有操作都有日志记录，便于调试和问题排查
7. **音量控制**: 音量控制应该通过 AudioModel 进行，而不是在播放器 Model 中
8. **截图功能**: 截图功能应该通过 RenderView 的 TakeScreenshotCommand 触发
