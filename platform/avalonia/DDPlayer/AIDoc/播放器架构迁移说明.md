# 播放器架构迁移说明

## 概述

将播放器封装类从 `AvoxControls` 移动到 `AvoxCommon`，使这些类可以在任何 C# 项目中使用，不依赖 Avalonia UI 框架。

## 迁移的类

### AvoxCommon 中新增的类

1. **BasePlayer.cs**
   - 播放器基类，实现 `IMediaPlayerOb` 回调接口
   - 命名空间：`AvoxCommon`
   - 提供通用状态管理和事件通知

2. **NewMediaPlayer.cs**
   - 封装 `AvoxNet.IMediaPlayer` 接口
   - 命名空间：`AvoxCommon`
   - 提供媒体文件/直播流播放功能

3. **NewSourcePlayer.cs**
   - 封装 `AvoxNet.ISourcePlayer` 接口
   - 命名空间：`AvoxCommon`
   - 提供直出设备源播放功能

4. **NewRtcPlayer.cs**
   - 封装 `AvoxNet.IRtcPlayer` 接口
   - 命名空间：`AvoxCommon`
   - 提供 WebRTC 推拉流功能

5. **AudioModel.cs**
   - 封装 `IAudioRender` 接口
   - 命名空间：`AvoxCommon`
   - 提供音量控制、静音等功能

### AvoxControls 中更新的类

1. **MediaModel.cs**
   - 更新为使用 `AvoxCommon.MediaPlayer`
   - 保持原有功能不变

2. **SourceModel.cs**
   - 更新为使用 `AvoxCommon.SourcePlayer`
   - 保持原有功能不变

3. **RtcModel.cs**
   - 更新为使用 `AvoxCommon.RtcPlayer`
   - 保持原有功能不变

4. **RenderView.cs**
   - 保持在 `AvoxControls` 中（因为依赖 Avalonia 的 NativeControlHost）
   - 截图功能已添加

## 命名空间变化

### 旧命名空间

```csharp
namespace AvoxControls
{
    public class BasePlayer : IMediaPlayerOb { }
    public class MediaPlayer : BasePlayer { }
    public class SourcePlayer : BasePlayer { }
    public class RtcPlayer : BasePlayer { }
    public class AudioModel : INotifyPropertyChanged { }
}
```

### 新命名空间

```csharp
// 核心播放器封装在 AvoxCommon 中
namespace AvoxCommon
{
    public abstract class BasePlayer : IMediaPlayerOb { }
    public class MediaPlayer : BasePlayer { }
    public class SourcePlayer : BasePlayer { }
    public class RtcPlayer : BasePlayer { }
    public class AudioModel : INotifyPropertyChanged { }
}

// UI Model 在 AvoxControls 中，引用 AvoxCommon 的类
namespace AvoxControls
{
    public class MediaModel : INotifyPropertyChanged
    {
        private AvoxCommon.MediaPlayer player;
    }

    public class SourceModel : INotifyPropertyChanged
    {
        private AvoxCommon.SourcePlayer player;
    }

    public class RtcModel : INotifyPropertyChanged, ISdpAgentOb
    {
        private AvoxCommon.RtcPlayer player;
    }

    public class RenderView : NativeControlHost
    {
        // 保持不变，使用 Avalonia 的 UI 组件
    }
}
```

## 使用示例

### 1. 在非 Avalonia 项目中使用

```csharp
using AvoxCommon;

// 直接使用 AvoxCommon 中的播放器类
var mediaPlayer = new AvoxCommon.MediaPlayer();
mediaPlayer.Open("D:/Videos/test.mp4");
mediaPlayer.Seek(10000);

// 使用 AudioModel
var audioModel = new AudioModel.AudioModel();
audioModel.AudioRender = mediaPlayer.GetAudioRender();
audioModel.Volume = 0.8;

// 获取状态
AvoxLog.logMsg(LogLevel.info, $"播放状态: {mediaPlayer.GetState()}");
```

### 2. 在 Avalonia 项目中使用

```csharp
using AvoxCommon;
using AvoxControls;

// 使用 UI Model
var mediaModel = new AvoxControls.MediaModel();
var renderView = new AvoxControls.RenderView();
var audioModel = new AvoxCommon.AudioModel();

// 绑定渲染器
renderView.WindowRender = mediaModel.GetSurfaceRender();

// 绑定音频渲染器
audioModel.AudioRender = mediaModel.GetAudioRender();

// 打开媒体
mediaModel.Open("D:/Videos/test.mp4", IoPlan.ffmpeg, true);

// 设置音量
audioModel.Volume = 0.7;

// 截图
renderView.OnTakeScreenshotRequested += (sender, e) =>
{
    // 处理截图
    Console.WriteLine("截图触发");
};
```

### 3. 在其他 C# 项目中使用

```csharp
using AvoxCommon;

class Program
{
    static void Main(string[] args)
    {
        // 使用 SourcePlayer 进行设备预览
        var sourcePlayer = new AvoxCommon.SourcePlayer();
        
        // 创建摄像头源
        var cameraSource = VideoManager.Get().createVideoSource(DeviceType.camera);
        sourcePlayer.SetVideoSource(cameraSource);
        
        // 打开预览
        sourcePlayer.Open();
        
        // 创建音频控制
        var audioModel = new AudioModel.AudioModel();
        audioModel.AudioRender = sourcePlayer.GetAudioRender();
        
        // 设置音量
        audioModel.Volume = 0.9;
        
        Console.WriteLine($"播放状态: {sourcePlayer.GetState()}");
    }
}
```

## 优势

1. **解耦**: 播放器封装不依赖 Avalonia UI 框架
2. **复用**: 可以在任何 C# 项目中复用这些类
3. **清晰**: `AvoxCommon` 作为通用库，`AvoxControls` 作为 Avalonia 特定 UI
4. **灵活**: UI Model 可以选择使用哪个播放器类型

## 注意事项

1. **引用添加**: 如果在非 Avalonia 项目中使用，需要添加对 `AvoxCommon` 的引用
2. **命名冲突**: AvoxCommon 中已有旧的播放器类（AvPlayer.cs, MediaPlayer.cs, SourcePlayer.cs），新类使用 `New` 前缀区分
3. **日志系统**: 新类使用 `AvoxLog.logMsg()` 进行日志记录，保持一致性
4. **后续清理**: 确认新架构稳定后，可以删除旧的播放器类
