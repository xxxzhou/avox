w# avox 工具主界面 (Hub) 设计 —— 工具 launcher

> 状态:**设计稿**(2026-08-07)。落地实现见 `platform/godot/tools/src/hub/`(main.gd / main.tscn),`project.godot` 主场景指向它。
> 定位:工具 launcher。`tools/` 是 avox Godot UI 工具箱,本界面作为**入口**,主界面里选择工具(播放器 / 语音输入 / 后续更多)。语音输入自身 UI 不在本设计范围(模型检查与下载在此完成)。

---

## 1. 定位与目标

- **无边框小窗 launcher**:hub 是**无边框小窗**(500×560 居中,参照 voiceinput)的工具选择器;按住空白拖动、右上角 ✕ / Esc 退出;进入工具时恢复常规窗口(1280×720,有标题栏)。
- **入口即枢纽**:主界面只做「选工具」,不做工具本身;选中即切场景,工具可返回主页。
- **可扩展**:工具列表数据驱动(`_tools` 数组),加工具 = 加一条 `{glyph, title, desc, scene, asset?}`。
- **资源把关**:工具若依赖运行时资源(如语音输入依赖 STT 模型 `sherpa_zh_en`),主界面检查清单 `assets_manifest.json`,**缺失自动提示并开始下载**,就绪才可进入。
- **风格**:对齐既有播放器 —— 深色底、半透明面板、单一强调色 `#3B82F6`、圆角 12。

### 1.1 工具清单(v1)

| 工具 | 入口场景 | 依赖资源 |
|---|---|---|
| 播放器 | `src/mediaplayer/main.tscn`(已落地) | 无 |
| 语音输入 | `src/voiceinput/voice_input.tscn`(由**另一会话**交付,本 hub 仅入口) | `sherpa_zh_en`(STT 流式模型,168MB) |

## 3. 功能

### 3.1 工具卡
- 点击 → `change_scene_to_file(tool.scene)`;工具场景内「返回主页」切回 hub。
- 卡片声明 `asset` 时,渲染资源状态角标:就绪(绿点)/ 缺失(黄点 + [下载])/ 下载中。

### 3.2 资源状态面板
- 读 `assets_manifest.json`(部署根 `assets/script/`),统计 `method=="download"` 项:汇总「共 N 项 · 全部就绪」或「缺失 K 项(见下)」。
- **小窗口原则**:只列**缺失/下载中**的可操作行(名称 / 大小 / 状态 / [下载]);全就绪时面板就一行汇总,保持窗口紧凑。
- 数据来自 `fetch_assets.py check --json`(唯一权威),面板只展示。

### 3.3 缺失自动提示 + 下载(核心)
```
[hub _ready] → AssetManager.check_item("sherpa_zh_en")
    ├─ 就绪 → 卡片绿点,直接可用
    └─ 缺失 → 弹 ConfirmationDialog「语音输入依赖 STT 模型(sherpa_zh_en,约168MB)未下载,立即下载?」
          ├─ [下载] → AssetManager.download_item() 后台线程下载,行显「下载中…」
          └─ [稍后] → 面板保留 [下载] 按钮,随时可下
   完成 → download_finished → 刷新状态,绿点 + toast「下载完成」
```
- 下载复用 `fetch_assets.py download --select <id> --root <部署根>`,后台 `Thread` 执行,不卡 UI;失败显示 msg。

## 4. 技术方案

### 4.1 AssetManager(autoload)
选 autoload 而非场景子节点:`change_scene_to_file` 会释放场景,下载中的 `Thread` 不能随之销毁;autoload 跨场景存活,hub 与语音占位页共享同一信号与缓存。

| 能力 | 实现 |
|---|---|
| 部署根 | `ProjectSettings.globalize_path("res://addons/avox_godot/bin")`(junction → avox 安装树,FileAccess/OS.execute 透明) |
| python | 依次试 `python`/`py`;均无则资源检查优雅降级 |
| 检查 | `fetch_assets.py check --json --no-color --root <根>` → `"\n".join(out)` → JSON,缓存 `_checked` |
| 下载 | `Thread` → `OS.execute(py, [...download --select id --root...])`,worker 不碰场景 API;`_process` 里 `wait_to_finish()` 取回,主线程发信号 |
| 信号 | `check_failed(msg)` / `download_started(id)` / `download_finished(id, ok, msg)` |

### 4.2 导航
- `project.godot`:`run/main_scene` → hub;`[autoload] AssetManager`。
- mediaplayer 文件菜单加「返回主页」;语音场景由另一会话交付并自带「返回主页」,hub 不做占位页(`ResourceLoader.exists()` 守卫:未交付则 toast「语音输入开发中(另一会话)」,已交付自动可切)。
- 插件节点跨场景销毁安全:`voice.cpp`/`player.cpp` 已有 `NOTIFICATION_EXIT_TREE` 停钩子/线程。

## 7. 已知坑 / 风险

| 坑 | 对策 |
|---|---|
| 后台线程 `OS.execute`(Win,官方未声明线程安全) | worker 只 OS.execute+本地数组,`wait_to_finish` 取回;`open_console=false` 不闪控制台;异常回退 `OS.create_process`+轮询临时文件 |
| junction 未部署 → 清单缺失 | 视为「不可用」,hub 顶部显部署提示,不崩 |
| python 不可用 | `python`→`py` 回退;仍无则报「资源检查不可用」 |
| 退出时下载线程未结束(168MB) | `_exit_tree` `wait_to_finish`,v1 接受(阻塞退出);可取消下载为后续扩展 |
| `fetch_assets.py` JSON 为多行 | 必须先 `"\n".join(out)` 再 `JSON.parse_string`(检查/下载两处) |
