# 语音输入 —— Godot 实现方案

> 状态:**设计稿**(2026-08-07)。插件封装 avox 底层 API(STT/麦克风/热键/注入),**语音流程在 GDScript 重写**(功能先对齐 `avox_cli voice`),UI 落 `tools/src/voiceinput/`。
> 行为基准:`src/avox_cmd/commands/CmdVoice.cpp`(CLI 版,Windows only)。

## 1. 现状与动机

cmdVoice 是全局语音输入:常驻后台 → 全局热键(默认 F9)→ 麦克风录音 → sherpa 流式识别 → 文字 `SendInput Unicode` 逐字注入到当前焦点窗口(游戏聊天框/记事本),hold/toggle 两模式,配置在 `assets/config/cli.json` 的 `voice` 节点。

移植动机:① 设置没 UI,要手改 cli.json;② 过程不可见,partial 只刷控制台;③ 播放器工具本来就在跑,挂上去即可。

## 2. 总体架构

```
GDScript(流程+UI) tools/src/voiceinput/ → voice_input.gd 编排 + 窗口 + 设置弹窗
        ↓
插件 API 封装(GDExtension, 4 类薄封装) → GlobalHotkey / MicCapture / SttNode / TextInjector
        ↓
avox C API + Win32
```

**必须留在插件**:全局热键钩子(焦点在别的窗口仍生效)与 `SendInput` 注入 —— Godot `_input` 只收本窗口键盘事件,GDScript 做不到。其余(状态机、增量 diff、前缀、配置、UI)全在 GDScript。

## 3. 插件 API 封装(`plugin/src/voice.h/cpp`,注册 4 类)

| 类 | 方法 | 信号 | 封装 |
|---|---|---|---|
| `GlobalHotkey` | `register(kind,name)→bool` / `unregister()` / `set_capture_mode(bool)` / `set_active_mode(kind)` / `get_active_mode()` / `get_hotkey_display(kind)` (`kind`=`"toggle"`/`"hold"`) | `pressed` / `released` / `toggled` | `WH_KEYBOARD_LL` 钩子,**单模式开关** `active_mode`:**两套热键都注册,但只有当前模式热键响应**——toggle 热键→`toggled`,hold 热键按下→`pressed`/抬起→`released`;切模式即时生效(复位按下标志);全吞热键防修饰键污染;后台消息循环线程,信号经队列+`_process()` 排空 |
| `MicCapture` | `list_devices()→PackedStringArray` / `start()` / `stop()`,`device_index`、`open_frame_ms`(默认100)属性 | `audio_desc(sr,ch)` / `audio_frame(data)` | `createDevicePlayer`+`IAudioRender::openTap`,tap 线程推队列主线程发 |
| `SttNode` | `start()` / `stop()` / `loading()` / `recognize(data)` / `set_model_level` / `set_recognizer_type`(默认 base/streaming) | `partial_result(text)` / `final_result(text)` / `stt_ready` / `error(msg)` | `createAudioStt(sherpa)`+`addAudioSttOb`;**对象跨轮复用**(`stop()` 只重置 stream 不销毁,模型不重载);信号名用 `stt_ready` 避 Node 内置 `ready` |
| `TextInjector` | `inject_unicode(text)` / `send_backspace(n)` / `can_inject()` / `set_capture_mode(bool)` | — | `SendInput KEYEVENTF_UNICODE` 原语,不追踪 lastText(**增量 diff 在 GDScript 算**) |

## 4. 流程重写(`tools/src/voiceinput/voice_input.gd`)

编排器持 4 节点,复刻 cmdVoice。**单模式开关 + 双热键** —— 顶栏 `[toggle|hold]` 切当前生效模式(每模式各记各的热键,默认 F9 / F10),只有当前模式热键响应;单击热键钮改绑**当前模式**热键:

```gdscript
stt.start()                                   # _ready 预加载模型 (后台线程)
stt.stt_ready.connect(_register_hotkeys)      # 模型就绪 → 注册两套热键 (先模型后钩子)
hotkey.toggled.connect(_on_toggle)            # toggle 模式热键
hotkey.pressed.connect(_on_hold_down)         # hold 模式热键按下 → 热键钮高亮 + start
hotkey.released.connect(_on_hold_up)          # hold 模式热键抬起 → 复位 + stop

func _register_hotkeys():
    hotkey.register("toggle", hotkey_toggle)
    hotkey.register("hold", hotkey_hold)
    hotkey.set_active_mode(mode)              # 只有当前模式热键响应

func _set_mode(m):                            # 切模式: 更新开关高亮 + 热键钮显示 + active_mode
    mode = m; _sync_mode_ui(); _save_config()

func start(src):                              # src = "toggle" | "hold"
    if not stt_ready: return                  # 未就绪提示
    stt.start()                               # 确保 STT 任务在跑 (幂等)
    mic.start(); src = src; recording = true; last_text = ""
func stop():
    mic.stop()                   # closeTap 排干尾部帧
    recording = false
    stt.stop()                   # 只重置 stream (对象复用, 模型不重载), 排空 final

mic.audio_frame.connect(func(d): stt.recognize(d))   # 帧转发

# 每句 final → 追加一行到 _lines; 窗口自动撑高 (紧凑一行 → 随行数增长)
func _on_final(text: String):
    inject_common_prefix_diff(text)   # 增量注入 (同 cmdVoice)
    _append_line(text)                # 每次一行
```

**行为对齐(别改)**:toggle/hold 热键才起,不在 UI 上直接录;`mic.stop()` 先 closeTap 再翻 `recording`(保句尾);`stt.stop()` 只重置 stream(防跨段串话),对象复用不重载模型;前缀拼在注入前;hold 释放不打断 toggle 轮(`_src` 记发起方);切模式不打断正在进行的录音轮。

## 5. 配置

`ConfigFile` 存 `user://voice_settings.cfg`,字段对齐 cli.json `voice` 节点:`mode`/`hotkey`/`prefix`/`device_index`。启动读 → 下发 → 启动编排器;改动即时落盘。

## 6. UI(`tools/src/voiceinput/`)

```
voice_input.gd · voice_input.tscn · key_capture.gd
```

### 6.1 语音输入窗口(主 UI) —— 无边框状态栏式微型悬浮条, 随行数自动撑高

`Window`, 无边框置顶的**状态栏式细条**(236×34, 默认停屏幕右上角),初始一行,识别文字每次一行追加在下方,窗口随之长高(上限 ~320px 封顶)。

**主窗口必须经 `DisplayServer` 设置, 节点属性不生效**:Godot 主窗口的 `size`/`borderless` 节点属性不会作用于 OS 窗口(实测设置后 OS 仍是 project.godot 的 1280×720 带标题栏)。必须 `DisplayServer.window_set_flag(WINDOW_FLAG_BORDERLESS/ALWAYS_ON_TOP, true, wid)` + `window_set_size` + `window_set_position`。且**窗口显示时 Godot/Windows 会把主窗口异步顶高**(如 34→64, 视口仍是 34)——`_process` 每帧核对 OS 尺寸, 跑偏就 `window_set_size` 钉回目标(无边框窗不可手动缩放, 钉住无副作用)。按住窗口任意空白拖动(全窗 `bg` Panel 收 `gui_input`)。

```
┌───────────────────────────────────┐
│ [toggle][hold]  F9  ● [⚙]        │  ← 一行顶栏 (切到 hold 时显示 F10)
├───────────────────────────────────┤
│  ✓ 你好世界                        │  ← 每次 final 一行
│  ✓ 再见                            │
│  🎤 正在识别…                     │  ← 录音中实时 partial
└───────────────────────────────────┘
```

顶栏控件:
- **模式开关** `[toggle|hold]`(两个 `toggle_mode` Button + `ButtonGroup` 单选):**单模式** —— 切到哪个模式就只听那个热键;各模式各记各的热键。切模式不打断正在进行的录音轮。
- **热键钮**(`KeyCapture`):显示**当前模式**热键(如 `F9`)。单击进入捕获态改绑当前模式热键;**hold 模式按住热键时按钮呈按下高亮**(钩子 `pressed`/`released` 驱动 `button_pressed`,`toggle_mode=true` 让按下态长驻)。
- **● 状态灯**:绿=待命 / 红=录音中 / 灰=模型未就绪。
- **⚙ 设置**:`PopupPanel`(前缀/麦克风/模型状态/清空历史/**退出**——无边框窗口没有系统关闭钮,退出靠这里)。

### 6.2 设置弹窗(顶栏「⚙」→ `PopupPanel`)

| 设置 | 控件 | 绑定 |
|---|---|---|
| 前缀 | LineEdit | `prefix` |
| 麦克风 | OptionButton(`mic.list_devices()` 填充) | `device_index` |
| 模型状态 | Label(`stt.ready`/`error`,未下载提示 `python script/fetch_assets.py`) | — |
| 清空历史 | Button | `_clear_history()` |
| 退出 | Button | `get_tree().quit()`(无边框窗口没有系统关闭钮) |

热键改绑不再进弹窗 —— 直接点顶栏热键钮(见 6.1),回填**当前模式**热键。

### 6.3 KeyCapture(`key_capture.gd`)

`Button` 子类:常态显示热键(`current_name` **赋值自动刷新显示**,编排器切模式后设 `current_name` 即可);点击→捕获态(`hotkey.set_capture_mode(true)`,防"设置 F9 时立刻触发录音")→按组合键→`captured(name)` → 编排器 `hotkey.register(mode, name)` 回填当前模式;`Esc` 取消,捕获期 `accept_event()` 吞键。hold 的按住高亮由编排器置 `button_pressed`(需 `toggle_mode=true` 才能长驻按下视觉;仅视觉,不触发捕获)。

### 6.4 节点树

```
Main
├─ VoiceWindow(Window, 置顶)  VoiceSettingsPopup(PopupPanel)
```

## 9. 已知坑(自 CLI 继承)

| 坑 | 对策 |
|---|---|
| 主窗口 `size`/`borderless` 节点属性不生效, OS 仍是 project.godot 的 1280×720 带标题栏 | 必须 `DisplayServer.window_set_flag(WINDOW_FLAG_BORDERLESS/ALWAYS_ON_TOP)` + `window_set_size` + `window_set_position`(见 6.1) |
| 窗口显示时被异步顶高(如 34→64, 视口仍是 34) | `_process` 每帧核对 `DisplayServer.window_get_size()`, 跑偏就钉回目标尺寸 |
| godot-cpp `String(const char*)` 按 Latin-1 读非 ASCII → 乱码 | avox 返回的 UTF-8 数据(设备名/识别文字)一律 `String::utf8(...)`;插件 C++ 中文文案**不能用窄字面量**(无 `/utf-8` 时是 GBK 字节,`String()`/`String::utf8()` 读都乱),用宽字面量 `L"…"` + `WideCharToMultiByte` 转 UTF-8 |
| 跨线程发信号崩 | 插件侧队列 + `_process()` 排空再 emit |
| 跨段串话 | `stt.stop()` 销毁重建 stream,勿用 OnlineStreamReset |
| 尾部丢字 | `mic.stop()` 先 closeTap 排干再翻 `recording` |
| 帧转发延迟 | v1 主线程转发可接受;敏感则 `MicCapture` 加 `forward_to(stt)` 直喂 tap 线程 |
| 模型未下载 | UI 提示 `python script/fetch_assets.py` |
| 新类注册/部署 | 首次编辑器/`--import` 扫描;`.gdextension` 勿入 Release |
