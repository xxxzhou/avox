# avox Godot 播放器界面设计 —— 沉浸式悬浮风格

> 状态:**已落地**(2026-08-07)。实现见 `platform/godot/tools/src/mediaplayer/`(main.gd / main.tscn / scrub_bar.gd),`project.godot` 主场景已指向它;Godot `--import` + 无头运行校验通过(无脚本错误)。
> 定位:沉浸式悬浮控制条,参考 Screenbox / Windows 11 现代播放器。视频居中,底部半透明控制条,鼠标静止自动淡出。

> **落地时踩坑两则**:① `CanvasLayer` 不是 `CanvasItem`,**没有 `modulate`**——HUD 整体淡出要淡其内的根 `Control`;② Godot 的 `%` 运算符**不支持 `%g`** 格式符,倍速文案用 `String.num(v, 2).pad_decimals(1) + "×"`。

---

## 1. 设计定位

### 1.1 目标
- **内容优先**:视频画面是主角,控件只是浮在画面上的临时工具。
- **沉浸**:播放时控件自动隐藏,鼠标不动即"退场";画面全屏展示,无系统窗口装饰感。
- **现代**:半透明控制条 + 圆角 + 细线性图标 + 单一强调色,告别 VLC 式笨重控件堆砌。

### 1.2 设计原则
| 原则 | 落地 |
|---|---|
| 自动隐藏 | 播放时鼠标静止 3s → 控制条淡出;移动鼠标/按任意键 → 淡入 |
| 层级分离 | 视频层(TextureRect)与 HUD 层(CanvasLayer)分离,HUD 永远盖在视频上 |
| 少即是多 | 默认只露核心控件;倍速/画质/更多收纳进右侧"更多"菜单 |
| 一个强调色 | 主操作(播放进度、中心播放钮 hover)用强调色,其余低饱和灰阶 |
| 直播适配 | `duration ≤ 0` 判定直播:时间区改"● 直播"红点,禁用 seek |

### 1.3 风格参考
- [Screenbox](https://windowsforum.com/windows-news.4/screenbox-the-modern-sleek-media-player-redefining-windows-video-experience.369353/)(Fluent:半透明磨砂 + 悬浮控制条 + 自动隐藏)
- [GNOME Showtime](https://www.makeuseof.com/gnomes-new-app-is-the-beautiful-media-player-linux-deserved/)(极简,控件该退场就退场)
- 视觉效果对标:底部渐变黑 + 半透明面板 + 细线图标 + 圆角进度条。

## 2. 整体布局

```
┌────────────────────────────────────────────────┐
│  ┌ TitleLabel「视频文件名」                    │ ← 顶部,淡入时显示,自动隐藏时一起淡出
│  │                                            │
│  │             ██████████████                  │
│  │             █  视频画面   █                 │ ← TextureRect, KEEP_ASPECT_CENTERED
│  │             █ (黑色衬底)  █                 │
│  │                                            │
│  │          ╭──── CenterPlay ────╮             │ ← 中心大播放/暂停钮(淡入时显示)
│  │          ╰  ◉ 大圆钮 + 图标  ╯             │    播到 ready/playing 后自动消失
│  │                                            │
│  ╭─ ControlBar ──────────────────────────────╮ │ ← 底部悬浮面板(圆角+半透明)
│  │ ▶  ──████████░░░░──────  00:42 / 09:58    │ │    ▶ 播放/暂停 | ScrubBar | 时间
│  │     🔊 ▬▬▬▬  [1.0x ▾]        [⋯]  ⛶      │ │    音量 | 倍速 | 更多 | 全屏
│  ╰───────────────────────────────────────────╯ │
└────────────────────────────────────────────────┘
```

**四层结构**(从下到上):

| 层 | 节点 | 说明 |
|---|---|---|
| 视频层 | `TextureRect`(全屏) | 承接 `player.get_texture()`,stretch 用 `KEEP_ASPECT_CENTERED`(黑边不裁切) |
| 遮罩层 | `ColorRect`(全屏渐变) | 底部 0~25% 处黑色线性渐变,保证控制条上文字可读(纯 alpha 渐变,零开销) |
| HUD 层 | `CanvasLayer`(layer=10) | 承载 ControlBar / CenterPlay / TitleLabel,整体 `modulate.a` 一起淡入淡出 |
| 播放器 | `MediaPlayer`(Node) | avox 播放器节点,`_process` 里自动把帧桥到纹理 |

## 4. 控制条细节

### 4.1 播放/暂停 `▶`
- 状态机:点播/中心钮 toggle `pause()` / `resume()`。
- 图标按 `state == playing` 切换 `Play`/`Pause`。
- `buffering` 态显示转圈/禁用(hint_text "缓冲中…")。

### 4.2 进度条 `ScrubBar`(核心自绘控件)
- 三层信息一图显示:**已播(accent)** / **已缓冲(次白)** / **轨道(深灰)**。
- 交互:点击跳转、拖拽 scrub;拖拽期间**只更新本地 value**,松手才 `seek(pos_ms)`,避免拖拽中狂 seek。
- 直播流(`duration ≤ 0`):整条禁用,不显示 buffered。
- 现 API 无 buffered 数据 → v1 用 `state == buffering` 时把 buffered 拉到 value,精确缓冲水位见 §7 扩展点。

### 4.3 时间
- 点播:`00:42 / 09:58`(`get_position`/`get_duration`,毫秒→`HH:MM:SS`)。
- 直播:`● 直播`(红点 + 文案),隐藏总时长与 seek。

### 4.4 音量 `🔊`
- 喇叭按钮 toggle 静音(记住静音前音量),`HSlider` 0~1 映射 `set_volume`。
- 图标随音量切 `VolumeMuted`/`VolumeHigh`。

### 4.5 倍速 `[1.0x ▾]`
- `MenuButton` + `PopupMenu`,项:`0.5x / 1.0x / 2.0x / 4.0x / 8.0x / 16.0x`。
- 选中调用 `set_speed(v)`,按钮文字显示当前倍速,选中项打勾。

### 4.6 更多 `[⋯]`(可选扩展)
- 收纳:画质/音轨/字幕/截图(avox 对应能力后续接)。

### 4.7 全屏 `⛶`
- `DisplayServer.window_set_mode(WINDOW_MODE_FULLSCREEN/WINDOWED)`,图标随状态切 `Fullscreen`/`Unfullscreen`。

### 4.8 中心大按钮 `CenterPlay`
- 淡入态显示(`none/opening/pause/stopped/completed`),`playing` 后淡出。
- 64px 圆 + 强调色填充,点击 toggle 播放/暂停。
- 首帧未出画面时显示"加载中"(转圈)。

### 4.9 顶部菜单栏(已落地)
- 顶部「文件 / 播放 / 视图」`MenuBar`,与底部状态栏同属 HUD 层,**随鼠标静止一起淡出/移动淡入**(条件同 §5.1)。
- 文件 → 打开文件…(系统 `FileDialog`)/ 打开直播源…(输入地址)/ 退出;播放 → 播放暂停、进退 5s;视图 → 全屏。
- 打开文件:Godot 内置 `FileDialog`(`ACCESS_FILESYSTEM` + 媒体过滤),选中即 `stop()` → 换 `url` → `play()`。
- 打开直播源:居中半透明小弹窗 + `LineEdit` 输入地址,回车/「播放」即切源;`Esc` 关闭。
- 拖放播放:`get_window().files_dropped` 接首个文件直接播。
- 菜单弹窗打开期间(`about_to_popup`/`popup_hide`)HUD 保持常显,避免菜单开着被淡出。
- 换源时复位进度/标题/状态;标题按"有扩展名显示文件名,否则显示完整地址"区分本地文件与直播流。

## 5. 交互与动效

### 5.1 自动隐藏(核心沉浸感)
```
[任意 input / 鼠标移动] → HUD.modulate.a = 1(0.2s Tween),隐藏 Timer 重启
[Timer 3s 到 && 正在播放 && 未拖拽 && 鼠标不在控制条上]
      → HUD.modulate.a = 0(0.35s Tween),Input.mouse_mode = MOUSE_MODE_HIDDEN
暂停 / buffering / 拖拽中 → 永不自动隐藏
```
- 关键:**隐藏时 `mouse_mode = HIDDEN`**(不是 CAPTURED,否则无法再收到移动事件);鼠标一动(任意 `InputEventMouseMotion`)重新淡入。

### 5.2 动效清单
| 动作 | 时长/曲线 |
|---|---|
| HUD 淡入淡出 | 0.2s / 0.35s,`cubic` |
| 进度条 hover 增粗 | 0.12s |
| 中心钮 hover | 缩放 1.0→1.08 + 透明度 |
| 按钮按下 | `pressed` StyleBox 微暗 |

### 5.3 键盘快捷键
| 键 | 动作 |
|---|---|
| `Space` | 播放/暂停 |
| `←` / `→` | 后退 / 前进 5s(直播禁用) |
| `Shift + ←/→` | 后退 / 前进 60s |
| `↑` / `↓` | 音量 ±10% |
| `M` | 静音 |
| `F` | 全屏 |
| `0` | 回开头 |
| `Esc` | 退出全屏 |

### 5.4 状态 → 表现映射(`state_changed` 信号)

| `get_state()` | 显示 |
|---|---|
| `0 none` / `1 opening` | 中心钮=加载转圈,禁止控制 |
| `2 ready` | 中心钮=播放,标题=文件名 |
| `3 playing` | 中心钮淡出,图标=暂停 |
| `4 pause` | 中心钮淡入,图标=播放 |
| `5 seek` | 进度条随 `get_position` 跟动 |
| `6 buffering` | 中心钮=转圈,控制条禁用 |
| `7 stopped` | 全部复位 |
| `8 completed` | 中心钮=重新播放,时间停在结尾 |

## 6. Godot 技术方案

### 6.1 场景节点树(`main.tscn`)

```
Main (Control, full rect)
├─ Video (TextureRect, PRESET_FULL_RECT)
│     expand_mode=EXPAND_FIT_WIDTH_PROPORTIONAL
│     stretch_mode=STRETCH_KEEP_ASPECT_CENTERED
│     material = VignetteShader(可选,后续)
├─ Vignette (ColorRect, full rect)          # 底部渐变压暗
│     material = GradientShader(纯 alpha 渐变)
├─ Hud (CanvasLayer, layer=10)               # 整体淡入淡出
│   ├─ TitleLabel (Label, 顶部居中)
│   ├─ CenterPlay (TextureButton, 居中)      # 64px 大圆钮
│   ├─ ControlBar (PanelContainer, 底部, 左右下 margin 12px)
│   │   └─ MarginContainer
│   │       └─ HBoxContainer (separation=12)
│   │           ├─ PlayBtn   (TextureButton, 28×28)
│   │           ├─ ScrubBar  (自定义 Control, 拉伸填满)
│   │           ├─ TimeLabel (Label, min_w=110, 等宽数字)
│   │           ├─ MuteBtn   (TextureButton, 28×28)
│   │           ├─ VolumeBar (HSlider, min_w=80)
│   │           ├─ SpeedBtn  (MenuButton)
│   │           ├─ MoreBtn   (TextureButton, 28×28)
│   │           └─ FullBtn   (TextureButton, 28×28)
└─ Player (MediaPlayer)
```

### 6.2 半透明面板
- `ControlBar` 用 `Theme` 里的 `StyleBoxFlat`:
  `bg_color = rgba(8,10,14,0.55)`, `corner_radius = 12`, `border = 1px rgba(255,255,255,0.08)`。
- **磨砂(backdrop blur)两档**:
  - 默认档(推荐,iGPU 友好):纯 alpha 半透明,零开销。
  - 高级档:面板 `CanvasItem` 挂 blur shader(`hint_screen_texture` 采样 + 高斯模糊),画面后透出磨砂。**注意**:Intel UHD 770 上屏幕采样有固定 GPU 开销(见 [GPU直通渲染方案](GPU直通渲染方案.md) §5),默认关,配 `ProjectSettings` 开关。

### 6.3 ScrubBar 自绘(推荐,最灵活)
不堆 `ProgressBar` 拼 buffered/played 两层——用自定义 `Control` 的 `_draw()` 一次画三段(轨道/已缓冲/已播)+ 胶囊圆角,`_gui_input()` 处理点击拖拽:
```
value    (0..1)  已播
buffered (0..1)  已缓冲(v1: state==buffering 时=buffered, 否则=value)
min/max  固定 0..1
信号: scrub_started / scrub_moved(v) / scrub_ended(v)
```
- hover 判定用 `mouse_entered/exited` + `_gui_input`,高 4→10px 用 Tween。
- 拖拽只在 `press` 内跟随,`release` 发 `scrub_ended`。

### 6.4 主题
- 建 `theme.tres`,`default_font_size = 13`,定义 `PanelContainer`/`Button`/`Slider` 的 StyleBoxFlat。
- 强调色做成常量(如 `const ACCENT := Color("#3B82F6")`),ScrubBar 里引用同一常量,**不散写颜色值**。

## 7. GDScript 骨架(落地参照)

```gdscript
extends Control
## avox 沉浸式悬浮播放器 —— 落地骨架
## 依赖: addons/avox_godot 已部署

const ACCENT    := Color("#3B82F6")
const HIDE_DELAY := 3.0
const FADE_TIME  := 0.35

var player: MediaPlayer
var _is_live := false
var _scrubbing := false
var _mute_before := 1.0
var _hide_timer := Timer.new()
var _playing := false

@onready var _video: TextureRect   = %Video
@onready var _hud: CanvasLayer     = %Hud
@onready var _center: TextureButton= %CenterPlay
@onready var _play_btn: TextureButton = %PlayBtn
@onready var _scrub: Control       = %ScrubBar
@onready var _time: Label          = %TimeLabel
@onready var _title: Label         = %TitleLabel
@onready var _vol: HSlider         = %VolumeBar
@onready var _speed: MenuButton    = %SpeedBtn

func _ready() -> void:
    player = MediaPlayer.new()
    add_child(player)
    player.url = _src_url()          # 测试地址(命令行/输入框)
    player.state_changed.connect(_on_state)
    player.completed.connect(func(): _center.disabled = false)
    player.play()

    _hide_timer.one_shot = true
    _hide_timer.wait_time = HIDE_DELAY
    _hide_timer.timeout.connect(_hide_hud)
    add_child(_hide_timer)
    _show_hud()

    _scrub.scrub_ended.connect(func(v): player.seek(int(v * player.get_duration())))
    _speed.get_popup().id_pressed.connect(_on_speed)

func _process(_d: float) -> void:
    if player == null: return
    var t := player.get_texture()
    if t: _video.texture = t
    if _playing:
        var dur := player.get_duration()
        if dur > 0.0 and not _scrubbing:
            _scrub.value = clampf(player.get_position() / dur, 0.0, 1.0)
            _time.text = "%s / %s" % [_fmt(player.get_position()), _fmt(dur)]

# ── 状态 ──
func _on_state(s: int) -> void:
    _playing = (s == 3)
    _play_btn.icon = get_theme_icon("Pause" if _playing else "Play", "Button")
    _center.icon   = get_theme_icon("Pause" if _playing else "Play", "Button")
    _center.visible = not _playing
    if s == 0 or s == 7:
        _playing = false
        _is_live = false
        _time.text = ""
    if s == 2:  # ready: 判定直播(点数播)
        _is_live = player.get_duration() <= 0.0
        _title.text = player.url.get_file()
        _update_live_ui()
    if s == 3 or s == 4:
        _show_hud()
    if s == 8:  # completed
        _center.visible = true

# ── 自动隐藏 ──
func _show_hud() -> void:
    _hide_timer.stop()
    if _hud.modulate.a < 1.0:
        var tw := create_tween()
        tw.tween_property(_hud, "modulate:a", 1.0, FADE_TIME).set_trans(Tween.TRANS_CUBIC)
    if Input.mouse_mode != Input.MOUSE_MODE_VISIBLE:
        Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
    if _playing and not _is_live:
        _hide_timer.start()

func _hide_hud() -> void:
    if not _playing or _scrubbing: return
    var tw := create_tween()
    tw.tween_property(_hud, "modulate:a", 0.0, FADE_TIME).set_trans(Tween.TRANS_CUBIC)
    Input.mouse_mode = Input.MOUSE_MODE_HIDDEN

func _input(e: InputEvent) -> void:
    if e is InputEventMouseMotion:
        _show_hud()
    elif e is InputEventKey and e.pressed:
        _show_hud()

# ── 键盘 ──
func _unhandled_input(e: InputEvent) -> void:
    if e is not InputEventKey or not e.pressed: return
    match e.keycode:
        KEY_SPACE: _toggle()
        KEY_LEFT:  player.seek(player.get_position() - (60000 if e.shift_pressed else 5000))
        KEY_RIGHT: player.seek(player.get_position() + (60000 if e.shift_pressed else 5000))
        KEY_UP:    _set_vol(clampf(player.volume + 0.1, 0.0, 1.0))
        KEY_DOWN:  _set_vol(clampf(player.volume - 0.1, 0.0, 1.0))
        KEY_M:     _toggle_mute()
        KEY_F:     _toggle_fullscreen()

func _toggle() -> void:
    if player.checkPlaying(): player.pause()
    else: player.resume()

# ── 时间格式化 ──
func _fmt(ms: float) -> String:
    var t := int(ms / 1000.0)
    return "%02d:%02d" % [t / 60, t % 60]
```

> 落地时另建 `ScrubBar.gd`(自绘)、`theme.tres`(样式)。骨架以「可运行」为验收目标,控件行为与 §4/§5 一一对应。

## 9. 插件 API 扩展点(可选,不阻塞 v1)

| 需求 | 现状 | 建议 |
|---|---|---|
| 已缓冲水位(buffered) | 无 | `MediaPlayer` 加 `get_buffered() → float`,底层取解码队列水位;v1 可先用 `state==buffering` 近似 |
| 视频真实分辨率 | `videoW/videoH` 已缓存未暴露 | 加 `get_video_size() → Vector2`,窗口按画面自适应用 |
| 码率/丢包率(RTSP) | avox `getRate/getLossRate` 未桥 | 加 `get_rate()/get_loss_rate()`,状态栏显示 |

## 12. 高 DPI / 移动端适配与视觉改版 (2026-08-29)

> 背景: 高 DPI 与手机端 UI 观感差。排查发现三处根因: ① emoji 字符图标跨平台不一致
> (Windows 彩色 Segoe UI Emoji / Android 缺字); ② DPI 缩放二次放大 (窗口×sc 后又设
> content_scale_factor, 逻辑视口缩水 → 1280 布局横向溢出, 详见
> [Windows高DPI窗口适配.md](Windows高DPI窗口适配.md)); ③ 触控目标过小 (28px 按钮)。

### 12.1 图标: emoji → 自绘矢量 (`icon_button.gd`)

`IconButton extends Button`, `_draw()` 里矢量绘制 (PLAY/PAUSE/REW/FFWD/VOL/MUTE/
FULLSCREEN/MORE/ELLIPSIS/CLOSE), 颜色跟随 `font_color`/`font_hover_color`, 叠加在
Button stylebox 之上 (text 保持空)。中心大钮/关闭钮同源。跨平台渲染完全一致。

### 12.2 触屏优先 (token 化尺寸)

`_touch = mobile/android/is_touchscreen_available`, 尺寸 token: 按钮 46/38、
输入行 40/34、进度条 28/20 (触屏/桌面)。触屏隐藏音量滑条+静音钮 (走硬件键)。
PopupMenu 统一 `_style_popup_menu`: 触屏字号 15、行距 9。

### 12.3 视频区手势 (`_unhandled_input`)

- 单击 (视频空白区, 经 mouse 模拟): 切换 HUD 显隐; 弹窗开着点外面 = 关闭。
- 双击: 左 1/3 -10s, 右 1/3 +10s, 中段全屏。
- 前提: 场景根 `mouse_filter = IGNORE`, 事件落到 `_unhandled_input`;
  控制条/弹窗 (STOP) 命中的事件天然不到这里。
- 配套修复: HUD 淡出后 `_hud_root.visible = false` —— modulate.a=0 的控件
  **仍会拦截点击**, 否则触屏点视频区会误触隐形按钮。

### 12.4 弹窗自适应与滚动

`_fit_popup(popup, min_w)`: 宽 ≤ 视口 90%、高 ≤ 85%, 所有弹窗打开时调用;
设置/信息弹窗内容包 ScrollContainer, 内容少收缩到实际高度、超出限高滚动
(手机高缩放下逻辑视口 ~870x390, 写死 560 宽/320 高会溢出)。

### 12.5 样式收敛与字体

- 重复 6 处的弹窗按钮样式收敛为 `_style_primary/_style_ghost/_style_combo/
  _style_dialog`; `_build_theme()` 提供 SystemFont 中文字体链
  (MiSans → HarmonyOS Sans SC → 微软雅黑 → …), 挂 `_hud_root.theme`,
  PopupMenu/FileDialog 单独赋 theme。
- 修复磨砂面板从未渲染的 bug: `_apply_acrylic` 原来把 stylebox 换成
  StyleBoxEmpty —— 零绘制几何导致 material 着色器永不执行 (弹窗=悬浮文字)。
  改为 `_flat(Color.WHITE)` 提供几何, 颜色/圆角/描边由 shader 输出决定。
- 字号体系: 正文 14、弹窗标题 16、hint 12; 控制条高度按 token 计算
  (`-(24 + scrub_h + 6 + btn_h)`), toast 悬浮于控制条上方。
